# 04 · 反馈模板与话术

> 效力声明：本文件按节号递增顺序执行；评分分制以 `02-rubric.md` 为准，本文件只定"怎么写"。家长版的措辞红线以本文第二节为唯一口径。
> 用途：写家长版、学生版之前读一遍。目标是**口径统一**：同一类问题，换一个学生也这么说。

## 一、通用措辞纪律

| 纪律 | 原因 |
|---|---|
| 每条意见都要有**原话或现象**做证据 | 没有证据的建议等于没说 |
| 难点用**证据**说，不用形容词说 | 「口齿不清」→「Eiffel Tower 音节连得太紧，被听成三个词」 |
| 不用标签式评价（基础差／态度不好／不用功） | 标签不提供改法，且伤关系 |
| **不把"念题念得准"当优点写**（家长版与学生版都不写） | 念题是这种作业形式的产物，**考试里是考官念题、考生根本不念**；把执行作业的底线动作写成语言成就，等于告诉家长"我找不到他别的优点"，反而显得反馈没内容。念题准确度只作**内部教研信号**（漏词 / 改词说明对句子结构没有整体感），写在作业记录与教师观察里；"做得好的地方"要写真实的语言表现（流利度、句子立得住、切题、用词） |
| **不预测总分、不承诺考试结果** | 口语只占一部分，推不出总分 |
| 结尾给一个**可验证的短期目标** | 「下次只看还有没有考官听不懂的整句」比「提高语法」有用 |
| 明确写**不要写稿背**（针对按词说的学生） | 写稿会把"按词往外蹦"的习惯加重 |
| 有畏难情绪的学生：先给具体肯定 + 问题只提 2 条 + 写明"做对就当场夸" | 反馈的目的是让他继续练，不是让他知道自己差（**这是第二节 4–6 条的唯一例外**） |
| **行文不要有 AI 味**（家长版与学生版都适用） | 破折号（`——`）删掉，改用逗号、句号或直接断句；避免"不是 X，是 Y"这类否定式排比，直接陈述；**也不要写比喻或成语式的说法**（"立得住""有层次""基本盘""苗头"），家长没法拿它对照录音，要写家长能自己听出来的现象；具体内容用小序号 `1、2、3、` 编号，方便家长扫读。整篇改完**读一遍**再交（去 AI 痕的通用清单见 `humanizer-zh` 技能） |
| 分数来源要标注 | 内部档案与学生版里：AI 给的分标 `AI 预估`，发音分标"语音评测引擎"或 `待教师填`；**家长版只写 `X / 5`，不写来源**（写来源会暴露工具链） |

**家长版与学生版的分工**：家长版放**官方口径的分项分**（每个维度 X/5），不放引擎原始分、不放带量化的技术指标（「几乎没有停顿」这类非量化描述可以留）；学生版可以放分项分与技术指标（标 `AI 预估`）。

## 二、家长版

### 2.1 硬红线：绝不能出现的东西

| 不能说 | 为什么 | 换成什么 |
|---|---|---|
| **引擎/工具的原始分**（如"发音 93.6/100"） | 会暴露工具来源，且不是官方分制 | 只放**官方口径的分项分**：每个维度 X / 5 |
| **带量化的技术指标**：语速 X 词/分、停顿 X 次、答题 X 词、字数 | 家长既看不懂也不关心 | 用感受型描述：「说得比较连贯，几乎没有卡顿」「有一题只回答了一句就结束了」 |
| **「AI、引擎、评测、讯飞、Whisper、识别、转写、数据、检测、测量、样本」** | **不能暴露有工具链参与**——家长看到的必须是老师本人听出来的 | 全部删掉。开头用「我逐题听完了」这类教师口吻 |
| 总分预测、目标分承诺 | 口语只占一部分，推不出总分 | 只谈本次表现与下一步 |
| **单篇家长版正文里的「总分」二字** | 单篇作业给不出总分的语境，写了就是把局部当整体 | 只谈本次表现；要谈总分等完整模拟。**唯一豁免是本段末尾的免责句本身**（那句含"不作为考试总分预估"，必须一字不改地保留） |
| **markdown 表格** | 微信里表格会散 | 纯文字，逐行写，方便直接粘到微信 |

**技术指标的分档口径**（实现见 `scripts/kpf_validate.py` 的 `TECH_PARENT_HARD` / `TECH_PARENT_COND`）：

- **无条件 error**（词本身就在量化）：`词/分`、`词／分`、`词每分`、`词/分钟`、`词／分钟`、`个词`、`字数`、`平均每题`。
- **带量化才算技术指标**：「停顿」「语速」。同一行出现阿拉伯数字（**行首序号不算**，否则编号列表会全中招），或 `次数 / 次 / 处 / 占比 / % / 百分之 / 每秒 / 每个 / 秒` 落在该词 ±12 字符内 → error；否则只给 warning。
  「几乎没有停顿」「语速偏快」这类自然话术可以留；**一旦带数字或次数必须删除**。
- 「数据」「样本」「测量」属上一行的禁用词，**无条件 error**：教师不会自然这么写，写了就是能看出工具链参与。

**「总分」的例外写死在这里**：单篇家长版正文除免责句外不得出现「总分」二字。

**自检口径**：把整段话念一遍 —— 既要能听出"这是老师给的分"，又不能听出"这是机器分析出来的"。

### 2.2 家长版固定结构（六段，唯一版本）

```
<学生名> <级别>口语作业反馈（<日期> · <作业名> · 共 N 道题）

一、本次评分（参照 <级别> 口语评分标准，各维度 0–5 分）
语法与词汇：1 / 5
话语组织：2 / 5          ← A2 Key 无此项，整行不写
发音：5 / 5
互动交际：待补（本次是独自录音，测不到和别人的对话能力）
这是单次录音的表现，不作为考试总分预估。

二、做得好的地方
1. <具体，带原句或现象>
2. <同上>

三、存在的问题
1. <问题名>：他说的 <原句> 应为 <改后>。<一句说明>
2. <同上>（共 4–6 条）

四、需要改进的方向
1. <对应问题 1 的可执行动作>
2. <对应问题 2 的可执行动作>

五、接下来重点 / 回家怎么配合
<一件事 + 具体量，并说明不用发给老师>

六、本次未涉及的部分
<如：本次是独自录音，测不到和别人的对话能力，课堂对话环节我会另外观察>
```

要点：

- **第一段的分项分是"官方口径"**（每项 X/5），可以给，也是家长最需要的；**引擎原始分、带量化的技术指标一律不进家长版**。
- **每个维度只能有一行分**：同一维度出现 ≥2 行分数，`kpf_validate.py` 判 error——多出来那行很容易被家长当成"真正的分"。
- **维度名用中文官方译名或英文原名都行**（`语法与词汇`／`Grammar and Vocabulary`、`话语组织`／`Discourse Management`、`发音`／`Pronunciation`、`互动交际`／`Interactive Communication`）；两种写法校验器都认，口径不变。
- **互动交际缺失时写"待补"**，并在第六段写明原因，不要编一个数。
- **逐行写，不用表格**；只有到"完整模拟"要给总分时，才需要写对满分与权重（A2 Key 45 分／B1 Preliminary 30 分／B2 First 60 分）。
- **单篇作业不给加权总分、不给得分率、不判过没过**（规则见 `02-rubric.md` 第六节）；**单篇家长版正文除免责句外不得出现「总分」二字**；只有完整模拟（覆盖全部 Part、四项齐备）时，才在"一、本次评分"里追加总分、得分率与参考判定。
- 整篇**英文原话合计不超过 6 句**（与"存在的问题"4–6 条一一对应，别各条都堆原句）；原话必须从转写稿照抄，防编造校验会按相似度判：**< 0.85 → error（疑似编造）**、0.85–0.92 → warning（有出入）、**≥ 0.92 通过**（阈值见 `06-verification.md` §8.4）。
- **唯一的条数例外**：有畏难情绪的学生按第一节缩到 2 条（问题与改进各 2 条），并在结尾写明"做对就当场夸"。
- 结尾给一个可验证的短期目标；明确写「不要写稿背」。
- 图片类题型未提供图片时（见 `01-task-map.md` 第六节），不得对"描述完整性/内容切题/有没有说错"下任何结论。

### 2.4 几个改写示例（难听的话怎么变成证据）

| 不要写 | 改成 |
|---|---|
| 孩子口齿不清 | 他说 Eiffel Tower（埃菲尔铁塔）音节连得太紧，听起来被拆成了三个普通的词。这不是生理问题，练朗读就能改 |
| 语法结构太差 | 他其实不是不懂规则，是**熟练到能脱口而出的句型太少**，一超出熟悉范围句子就散了。建议先把五个句型练到自动化 |
| 答非所问 | 这次第四题问的是"长假和几个短假你更喜欢哪个"，他答的是"我去年去北京玩了 14 天"——经历讲得很好，但"更喜欢哪个"这个问题没有回答，考试里会直接扣分 |
| 上课不专心 | 课上他的参与度其实很好、敢说，这是优势；我会多给他即时反馈，做对就当场肯定 |

## 三、学生版

学生版可以给分与技术指标，结构如下：

1. **你这次做到的三件事**（具体，带数字或原话）——先建立"我能行"。
2. **本次预估分**：只列可评的维度，标注 `AI 预估`（发音标来源或 `待教师填`），并说明哪几项本次没证据。
3. **逐句修改表**：原句 → 改后 → 为什么。**只列 5–8 句**，挑最有代表性的，不要全列。
4. **升级表达 2–3 句**：可直接背的 B2 说法，替换他的中式表达。
5. **下次课当场验收的 1 件事**：明确、可完成、当场给肯定。

## 四、常见追问 & 应答（教师备用）

| 家长可能问 | 应答要点 |
|---|---|
| 口齿不清是不是天生的？要不要去医院？ | 不是生理问题。依据很具体：他说 `Eiffel Tower` 被识别成三个普通单词，说明是音节连得太紧，不是哪个音发不出来。这类问题朗读训练最有效 |
| 语法这么弱，冲刺班来得及吗？ | 不是零基础、也不是不懂规则，是熟练句型太少，一紧张就退回最简单那几个。所以不刷语法题，走"固定句型 + 开口练"，见效比刷题快。这学期先不追量，追"说对、说完整" |
| 要不要另外买语法书或报语法课？ | 暂时不用。口语上暴露的问题要靠嘴改，多上一门课反而占时间。写作那边会同步带语法点 |
| 在家让他背范文、写稿练可以吗？ | **不建议**，这条对他特别重要。写稿会让他照着词念，正好加重"按词说"的毛病。直接开口、不写稿 |
| 考试目标还有多远？ | 口语只占考试的一部分，现在给出总分预测没有意义。先把这 2–3 个具体问题解决，下次作业就能看到变化 |
| 上课说话／提前做作业的事 | 已经处理：<具体动作>。冲刺班是讲评上节课作业，所以提前完成作业对他尤其关键 |
