# 交付前自检清单（全 skill 唯一一份）

这份清单是**全 skill 唯一**的自检清单：`SKILL.md`、`references/02-rubric.md`、`references/03-scoring-rules.md`、
`references/04-feedback.md`、`references/05-output-and-vault.md` 与 `scripts/kpf_report.py` 的模板里都不再自带清单，只指向本文件。

**只看生成后**：报告写完（成品文件已落盘）再逐项过一遍。本清单不要求"生成前先通读一遍"——那种双重自检会让人两头都不做。

**机械项跑命令，不靠读**：

```bash
# 家长版（把 <报告> <级别> 换成实际值）
python3 scripts/kpf_validate.py <报告> --kind 家长     --form 单篇 --level FCE
python3 scripts/kpf_validate.py <报告> --kind 学生     --form 单篇 --level FCE
python3 scripts/kpf_validate.py <报告> --kind 作业记录 --form 单篇 --level FCE
# 作业记录草稿形态（先存档后补分；占位符降为 warning，其余检查不变，交付前必须转正式）
python3 scripts/kpf_validate.py <作业记录> --kind 作业记录 --form 单篇 --level FCE --draft
# 防编造（给了转写稿才启用；阈值可用 --quote-threshold / --quote-warn-threshold 覆盖）
python3 scripts/kpf_validate.py <报告> --kind 家长 --form 单篇 --level FCE \
    --transcript work/<日期>-<学生>/<文件名>--local.json
# 规则是否漂移（阈值 / 满分 / A2 维度 / 防编造阈值 / 技术指标分级 / 维度中英对照 / 引用完整性 / 节号连续）
python3 scripts/check_consistency.py
```

校验器只用 Python 标准库，系统 `python3` 直接跑，不必进 `.venv`、不联网、不用凭证。
**有 error 的校验一律不通过：`kpf_validate.py` 退出码非 0（1）就是不可交付，必须重做；warnings 自己判断。**

**写/改任何门槛句之前，逐项特征回表核对级别**：把这句话断成"特征 × 级别"逐个查对应的档位表（references/02-rubric.md 各维度的分级表）——凡出现一个"该特征其实只属于某一级（或某一维度在某级根本不存在）"的，就必须拆成按级别写，或删掉只留"按上面表格对照"。这一步专门堵"用一句话概括四个维度的 5 档要求"这类错（例：把 B1/B2 的"尝试复杂结构、成段、主动发起推进"当成**通用**的 5 档条件写，会误压 A2——A2 没有话语组织这一维度、A2 的 5 档也不要求复杂结构与主动发起）。机械断言（`check_consistency.py` 第 10 项）只锁表格结构，**锁不住说明文字，这一步只能靠人做**。

## 🔴 P0 · 一定不能犯的错

### P0-1 不得编造学生没说过的话

**现象**：为了把"存在的问题"写满，顺手编一句学生没说过的话；家长一对录音就穿了。
**做法**：原句只从转写稿复制，**保留原始拼写**（`didn't been`、`always not` 这类照抄不改）；改后的句子另起一侧，不要混进原句。
**防编造阈值**（`scripts/kpf_validate.py` 的 `QUOTE_ERROR` / `QUOTE_PASS`，实测锚点见 `references/06-verification.md` §8.4）：
相似度 **< 0.85 → error**（疑似编造）；0.85–0.92 → warning（引用与原文有出入，请核对）；**≥ 0.92 通过**。
实测：逐字照抄 1.00 ｜ 只差标点 0.99 ｜ 少一处词 0.93（**必须仍通过**）｜ 同一句真话里换掉一个词 0.82（**必须 error**）｜ 完全编造 0.68。
`--quote-threshold` / `--quote-warn-threshold` 可覆盖这两个边界（后者必须大于前者，否则退出码 2）。

**这项检查必须真的跑过**（外部审查 2026-09-30 报出来的洞）：它**只在给了 `--transcript` 时才运行**，
所以"忘了加参数"和"检查通过"在退出码上原来长得一模一样——实测同一份编造原句的家长版，不传转写稿
`PASS`、传了 `FAIL`。现在**家长版与学生版不给 `--transcript` 就是 error**；确实拿不出转写稿时，只能加
`--no-transcript-check` 显式承认"本次未做这项检查"（会打进 stdout 摘要，不算静默放过）。

**自检**（引用对不上转写就报 error、退出码 1，并打印行号与相似度）：

```bash
python3 scripts/kpf_validate.py <报告> --kind 家长 --form 单篇 --level FCE \
    --transcript work/<日期>-<学生>/<文件名>--local.json
```

### P0-2 每条问题都要能追溯到音频或转写

**现象**：写出"注意力不集中""基础差"这类无法追溯的话。
**做法**：只把 **A 级（转写原句）/ B 级（脚本指标）** 当结论；C 级（低置信疑点、引擎不一致处）只能进抽听点位表，等教师听完再升级。见 `references/03-scoring-rules.md` 第一、二节。

**自检**：每条问题后面手写一行出处（`出处：转写 Q3` 或 `音频 00:34.2`）；抽听点位表里的条目不得写成"学生发音有问题"。

### P0-3 家长版红线：禁用词 / 带量化的技术指标 / 引擎原始分 / 正文的「总分」 / markdown 表格

**现象**：家长版里出现"语速 122 词/分钟""发音 93.6/100""| 维度 | 分数 |"。
**做法**：只放官方口径的分项分 `X / 5`；技术指标与引擎原始分留给内部档案与学生版；纯文字逐行写，不用表格。细则见 `references/04-feedback.md` 2.1。

技术指标分两档（实现：`TECH_PARENT_HARD` / `TECH_PARENT_COND`）：

- **无条件 error**：`词/分`、`词／分`、`词每分`、`词/分钟`、`词／分钟`、`个词`、`字数`、`平均每题`；
  「数据」「样本」「测量」也是无条件 error（能看出工具链参与）。
- **带量化才算技术指标**：「停顿」「语速」——同一行出现阿拉伯数字（行首序号不算），或 `次数 / 次 / 处 / 占比 / % / 百分之 / 每秒 / 每个 / 秒` 落在该词 ±12 字符内 → error；否则只 warning。
  「几乎没有停顿」「语速偏快」这类自然描述**可以留**，但一旦带数字或次数必须删除。

**自检**：

```bash
python3 scripts/kpf_validate.py <家长版> --kind 家长 --form 单篇 --level FCE     # 必须 0 error
grep -nE "AI|人工智能|引擎|评测|讯飞|Whisper|识别|转写|数据|检测|测量|样本|算法|模型" <家长版>   # 无输出
```

### P0-4 单篇作业只给分项分

**现象**：拿一页 Part 1 的发挥算出总分、得分率，判"过没过"。
**做法**：单篇只给每个维度 `X / 5` + 免责句；总分/得分率/参考判定只在**覆盖全部 Part、四项（A2 为三项）齐备的完整模拟**里给。见 `references/02-rubric.md` 第六节。
**「总分」在单篇家长版里一律 error，唯一豁免是免责句本身**——所以外面不能再出现这两个字。

**自检**：`python3 scripts/kpf_validate.py <报告> --kind 家长 --form 单篇 --level FCE`
（校验器会拦 `得分率`、`/ 45`、`/ 30`、`/ 60`、`未达`、`合格水平`、`过没过`，以及家长版正文里的 `总分`；免责句里的"总分"已豁免）
**免责句必须一字不改**：`这是单次录音的表现，不作为考试总分预估。`

### P0-5 A2 Key 只有 3 个维度，没有「话语组织」

**现象**：给 KET 作业硬造一项"话语组织"（写成 `话语组织` 或 `Discourse Management` 都一样算错）。
**做法**：A2 只有语法与词汇、发音、互动交际；描述图片题的完整度/顺序/时长在 KET 里只作**教师观察**。见 `references/01-task-map.md` 第二、六节。
**维度名中英等价**：中文官方译名与英文原名（`Grammar and Vocabulary` / `Discourse Management` / `Pronunciation` / `Interactive Communication`）校验器都认，不影响算分。

**自检**：`python3 scripts/kpf_validate.py <家长版> --kind 家长 --form 单篇 --level KET`
（校验器会拦"话语组织"维度行，中英文写法都拦；仅在行文中提及时给 warning）

### P0-6 发音分不能由 AI 自己编

**现象**：AI 凭转写文字估一个发音分填进家长版。
**做法**：发音分只有两个合法来源——**语音评测引擎**（讯飞 ISE，要标注"非官方考官分"、注明只覆盖念题部分）或**标 `待教师填`**。AI 只产出带时间戳的抽听点位表。见 `references/02-rubric.md` 第三节。

**自检**：家长版/学生版的发音行后面能指出来源；指不出就写「待补」，绝不能是自己估的数。

### P0-7 图片类题型：没拿到图片不得评"描述完整性 / 内容切题 / 有没有说错"

**现象**：只拿到音频，就断言"他漏说了一半元素"。
**做法**：描述照片 / 两图对比 / 看图说话**先向教师索要图片**；未提供时一律标注「未提供图片，描述完整性与准确性无法评估」，且不得对图片内容做任何猜测性结论。见 `references/01-task-map.md` 第六节。

**自检**：`grep -n "未提供图片\|图片" <报告>`，确认没有无图时的完整性结论。

### P0-8 独白 / 自问自答的互动交际标 `N/A` 或 `待补`，并写明原因

**现象**：没有对手方，却给互动交际编一个分。
**做法**：`--form` 决定措辞（`自问自答`/`独白` → 待补；`对话` → 教师评分）；含对手方的对话录音**绝不能被写成"自问自答"**。

**自检**：`python3 scripts/kpf_validate.py <报告> --kind 家长 --form 单篇 --level FCE`
（校验器发现"文中写了独自录音/无对手方，互动交际却给了分数"时直接报 error）

### P0-9 不把识别误差写成"学生说错了词 / 念错了音"

**现象**：把 `Eiffel Tower` 被识别成三个词，写成"学生发音有问题"。
**做法**：单一引擎的异常一律降为低置信疑点；要升级成结论必须**双引擎交叉验证**（`local` + `groq`，同位置 ±1.5 秒内都异常）。见 `references/03-scoring-rules.md` 第三节。

**自检**：点位表里每条疑点标明来源引擎与置信等级；没有第二引擎印证的不写进"存在的问题"。

### P0-10 念题差异告警与单题词数不得单独作为结论

**现象**：拿"多读 `you. Music.`"当朗读错误。
**做法**：对齐窗口有 **±2–4 词**边界误差，且会把上一题答案尾部算进题干。要判定朗读错误，必须回音频听，或确认差异词落在题干中段。见 `references/01-task-map.md` 5.1 节。

**自检**：`grep -n "多读\|念题差异" <底稿>` —— 命中处逐条问自己：是不是交界处的假阳性？

### P0-11 不预测考试分数或考试结果

**做法**：口语只占考试的一部分，不推总分、不承诺"下次能过"、不给目标分。家长追问时按 `references/04-feedback.md` 第四节的应答要点回答。

### P0-12 学生姓名 / 录音 / 学情只留本机

**做法**：不进任何仓库、不上传公开服务；本地转写（`--engine local`）就是为此默认的。音频一旦切到 Groq / 讯飞就会上传，切换前先确认。

**自检**：提交前看暂存差异，确认没有 `work/` 下的成品与转写、没有学生音频。

### P0-13 所有 AI 给的分都标 `AI 预估`

内部档案与学生版标 `AI 预估` / `语音评测引擎` / `待教师填`，三者的来源不要混成一个数（家长版只写 `X / 5`，不写来源）。

### P0-14 不换算剑桥量表分（如 160）

原始分 → 量表分的换算表只对官方练习卷有效，官方明确说不能用来预测真实考试分数；本 skill 不覆盖换算，也不得自行编造。

## 🟡 P1 · 必须做到

### P1-1 家长版六段齐备

本次评分 → 做得好的地方 → 存在的问题（4–6 条）→ 需要改进的方向（一一对应）→ 接下来重点与回家配合 → 本次未涉及的部分。唯一版本见 `references/04-feedback.md` 2.2。

**自检**：`python3 scripts/kpf_validate.py <家长版> --kind 家长 --form 单篇 --level FCE`（缺段会报错或警告）

### P1-2 家长版英文原话合计 ≤ 6 句

**自检**：同上（校验器数原句那一侧的英文句数，超过 6 句给 warning）

### P1-3 存在的问题 4–6 条，与"需要改进的方向"一一对应

畏难情绪的学生缩到 2 条，并写明"做对就当场夸"（这是唯一的条数例外）。

### P1-4 每个分数旁能写出 2–3 条证据

写不出证据就标 `证据不足`，不要猜一个分；同一处错误不在两个维度重复扣（答得太短算话语组织，不算语法词汇；流利度指标归话语组织，不归发音）。

### P1-5 作业记录是内部档案：原始分 + 映射分都要留

引擎原始分（如 `overall 93.6/100`）与映射后的 `X / 5`（`scripts/kpf_xfyun.py` 的 `to_band()`）并存；硬指标表、逐项详评、教师观察、抽听点位表齐备。

**自检**：`python3 scripts/kpf_validate.py <作业记录> --kind 作业记录 --form 单篇 --level FCE`
（有映射分却全文无原始分 → warning）

### P1-6（可选）落库走两阶段

草稿先写进使用者定义的"待确认"目录，教师确认后才进正式目录（映射见 `references/05-output-and-vault.md` 第二节）。**落库是可选步骤：不用笔记库时跳过，不影响交付。**

### P1-7 转写原文随档案归档

可读 `.md` 与引擎原始 JSON 一起归档到**同一作业目录** `work/<日期>-<学生>/`，作业记录里指向它（见 `references/05-output-and-vault.md` 第一节）。

### P1-8 跨批次对比必须同引擎

不同引擎的词数、停顿数不可比（`local` 的停顿系统性偏少约 67%）；改正版 vs 原版必须用同一个引擎。见 `references/06-verification.md` 第二节。

### P1-9 改正版作业逐条核验

学生重录后逐条对照"上次反馈的每一条是否落地"，而不是只重跑一遍分数。见 `references/05-output-and-vault.md` 第二节（改正版作业）。

### P1-10 作业记录可以先落「草稿」形态，但交付前必须转正式

**做法**：frontmatter 写 `状态: 草稿`（或校验时加 `--draft`），满篇 `〔待填〕` 也能先存档。草稿形态下**只有占位符残留降为 warning**，其余检查（禁用词、引擎原始分、维度分范围、结构段齐备、单篇不给总分）一律不变。见 `references/05-output-and-vault.md` 第二节。
**必须做到**：草稿通过时 stdout 会标 `（草稿形态：占位符 N 处未填，交付前必须补全…）`——看到它就不能当成品交付；填完占位符、把状态改正式、不带 `--draft` 重跑为 0 error 之后才算可交付（若启用落库，才能移进正式目录）。
**`--kind 家长` / `--kind 学生` 不接受 `--draft`**（传了就是用法错误，退出码 2）。

**自检**：

```bash
python3 scripts/kpf_validate.py <作业记录> --kind 作业记录 --form 单篇 --level FCE --draft   # 草稿：0 error 即可
python3 scripts/kpf_validate.py <作业记录> --kind 作业记录 --form 单篇 --level FCE           # 正式：必须 0 error
```

## 🟢 P2 · 打磨项

### P2-1 抽听点位表时间戳精确到 0.1 秒

教师能直接跳位听。

### P2-2 结尾给一个可验证的短期目标

「下次只看还有没有考官听不懂的整句」比「提高语法」有用。

### P2-3 明确写"不要写稿背"

针对按词往外蹦的学生；写稿会加重这个毛病。

### P2-4 与学生主页的学情标签、家长反馈做三方印证

三者一致时在教学结论里写明，比单次批改更有说服力。

### P2-5 同一个错误出现在 ≥2 名学生身上 → 升级为班级共性卡

共性卡里必须写 3 分钟能做完的课头操练。见 `references/05-output-and-vault.md` 第二节（错误卡与班级共性卡）。

### P2-6 难点用证据说，不用形容词说；不用标签式评价

「口齿不清」→「`Eiffel Tower` 音节连得太紧，听起来被拆成了三个普通的词」。
