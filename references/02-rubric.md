# 02 · 四项评分锚点与官方分制

> 效力声明：本文件按节号递增顺序执行；本文件的官方分制与「单篇 / 完整模拟」口径是**全 skill 的最终裁定**，其他 reference 与 SKILL.md 冲突时以本文件为准。
> **本表是教学用简写，不是官方评分标准原文。** 官方 descriptors（Cambridge English Speaking Assessment Scales）为权威依据，正式评分请以官方文件为准。
> 每档按 KET(A2) / PET(B1) / FCE(B2) 分别给锚点，因为同一表现放在不同级别要求下得分不同。

## 用法

1. 先确定级别（KET / PET / FCE），并按下表确认**该级别有哪几个维度**（A2 只有 3 个，没有话语组织）。
2. 对每一维度，从 5 分往下读，读到"这个学生的表现达不到这一档"的下一条，就是他的分。
3. **分数必须落在证据上**：每个分数后面能立刻写出 2–3 条原句或指标数字。写不出就说明证据不足，标 `证据不足` 而不是猜一个分。
4. **允许半分**（官方明确 "Examiners may award half marks"），所以 3.5 是合法的；只在证据确实落在两档之间时才用。
5. 标注来源：`AI 预估` / `教师判定` / `语音评测引擎`，三者不要混成一个数。
6. **AI 不给发音分**。发音分由语音评测引擎给，或标 `待教师填`（见第三节）。

维度名**中文官方译名与英文原名等价**，校验器两种写法都认（实现见 `scripts/kpf_validate.py` 的 `DIM_ALIASES`）：

| 中文官方译名 | 英文原名（大小写不敏感；`and` 与 `&` 等价） |
|---|---|
| 语法与词汇 | Grammar and Vocabulary / Grammar & Vocabulary |
| 话语组织 | Discourse Management |
| 发音 | Pronunciation |
| 互动交际 | Interactive Communication |

中文名是主口径，英文名只作等价识别——**怎么称呼不影响任何算分逻辑**。

| 级别 | 维度 | 话语组织 |
|---|---|---|
| A2 Key（KET） | 语法与词汇、发音、互动交际 | **无此项** |
| B1 Preliminary（PET） | 语法与词汇、话语组织、发音、互动交际 | 有 |
| B2 First（FCE） | 语法与词汇、话语组织、发音、互动交际 | 有 |

**读下面四节的锚点表之前，先记住两条官方口径**（这两条决定了每一格怎么写）：

1. **偶数档没有独立描述。** 官方量表在 4 档与 2 档不写自己的描述词，写的是"与相邻两档的特征混合"——4 档 = 3 档 + 5 档的混合，2 档 = 1 档 + 3 档的混合；0 档 = 整体表现低于 1 档（官方原表写作 `Performance below Band 1`）。四节锚点表的 4 / 2 档都按这个口径写：**4 档不是另一条独立的高门槛**，它就是 3 与 5 之间。
2. **同一维度的档位是跨级别平移的。** 官方量表里，某一级别的 1 档与低一级别的档位几乎同句：B2 语法词汇 1 档与 A2 语法词汇 5 档**逐字相同**；B2 发音 1 档 = B1 发音 3 档 = A2 发音 5 档（三处同句）；B2 话语组织 1 档 ≈ B1 话语组织 3 档；B2 互动交际 1 档 = B1 互动交际 3 档。所以 **B2 的 1 档不是"什么都不会"，而是"用 A2 水平在 B2 的考场里说话"**。写完一句档位描述后回表核对：你写的是官方那一档，还是更低一级的档。

## 一、语法与词汇 Grammar and Vocabulary

**来源**：以下锚点转述自 Cambridge 官方 Speaking assessment scales 的"语法与词汇 / Grammar and Vocabulary"一栏（A2 量表在 A2 Key for Schools 手册、B1 量表在 B1 Preliminary for Schools 手册、B2 量表在 B2 First for Schools 手册）。**下面各节写的 pXX 都是手册的印刷页码**：A2 量表印刷 p45（PDF 第 47 页）、B1 量表印刷 p64（PDF 第 64 页）、B2 量表印刷 p82（PDF 第 84 页）。**同一个维度的 5 / 3 / 1 档按级别各有一张表**，因为同一段表现放到不同级别的量表里档位不同。官方英文原文为准，本节是教学用中文转述。

### A2（KET）

| 分 | 锚点（官方 A2 量表 · 中文转述） |
|---|---|
| 5 | 对**简单**语法形式有良好的掌控；谈**日常情境**时能用上**一系列**恰当词汇 |
| 4 | 介于 3 档与 5 档之间（官方偶数档口径：与相邻两档特征混合） |
| 3 | 对简单语法形式有**够用**的掌控；日常情境的词汇**恰当**（只要求恰当，不要求范围） |
| 2 | 介于 1 档与 3 档之间（同上） |
| 1 | 只对**少数几种**语法形式有有限掌控；词汇只撑得起**孤立的词与短语** |
| 0 | 低于 1 档的表现 |

### B1（PET）

| 分 | 锚点（官方 B1 量表 · 中文转述） |
|---|---|
| 5 | 对简单语法形式有良好的掌控，**并尝试一些复杂结构**；谈**熟悉话题**时能用上**一系列**恰当词汇 |
| 4 | 介于 3 档与 5 档之间（官方偶数档口径：与相邻两档特征混合） |
| 3 | 对简单语法形式有良好的掌控；谈熟悉话题时能用上**一系列**恰当词汇 |
| 2 | 介于 1 档与 3 档之间（同上） |
| 1 | 对简单语法形式有**够用**的掌控；熟悉话题的词汇**范围有限** |
| 0 | 低于 1 档的表现 |

### B2（FCE）

| 分 | 锚点（官方 B2 量表 · 中文转述） |
|---|---|
| 5 | 对**有一定范围的简单形式、并含一些复杂形式**有良好的掌控；能就**范围较广**的一批熟悉话题用一系列恰当词汇交换看法 |
| 4 | 介于 3 档与 5 档之间（官方偶数档口径：与相邻两档特征混合） |
| 3 | 对**简单**语法形式有良好的掌控，并**尝试一些复杂结构**；能就一批熟悉话题用一系列恰当词汇交换看法 |
| 2 | 介于 1 档与 3 档之间（同上） |
| 1 | 对简单语法形式有良好的掌控；谈**日常情境**时能用上一系列恰当词汇（措辞与 A2 的 5 档相同） |
| 0 | 低于 1 档的表现 |

**看什么**（用来定位落在上面哪一档，不是官方判据之外的第二套扣分规则）：

- **两条官方判据**：① 简单形式的掌控程度（有限 / 够用 / 良好）；② 词汇的范围与恰当性（孤立词短语 / 恰当 / 一系列）。**先看这两条，再谈别的。**
- **只把简单句说好，B1/B2 顶多到 3 档**：官方 5 档比 3 档多出来的正是"并尝试一些复杂结构"（B1）、"有一定范围并含一些复杂形式"（B2）。这是 B1/B2 上不去 5 档最常见的真实原因，A2 不适用这一条（A2 从 1 到 5 档都只要求简单形式）。
- **"够用"不等于"有范围"**：官方 3 档的词汇只要求恰当，5 档才要"一系列"。把"够用"读成"有范围"，就是把 3 档抬成 5 档。
- **错误密度只用来定位档位，不能脱离档位描述单独扣分**：官方 3 档（B1/B2）的原文是"对简单形式有良好的掌控"，它允许错误可见——官方对 B2 3 档真实考生的评语里逐条列了七八处失误，档位仍是 3。所以错误密度用来区分 3 与 1、3 与 0，**不是**用来把 3 压到 2。
- 可量化抓手：错误数 ÷ 词数、可解句比例、结构类型数、有没有出现高于级别的词汇与句型（最后一条只在 B1/B2 争 5 档时算依据）。

## 二、话语组织 Discourse Management

**A2 Key 没有这一维度**，给 A2 作业打分时跳过本节（官方 A2 量表只有语法与词汇、发音、互动交际三项，没有话语组织）。

**来源**：以下锚点转述自 Cambridge 官方 Speaking assessment scales 的"话语组织 / Discourse Management"一栏——B1 Preliminary for Schools 手册 p64、B2 First for Schools 手册 p82。官方英文原文为准，本节是教学用中文转述。4 / 2 档按官方偶数档口径写（见本文件开头"读锚点表之前"）。

### B1（PET）

| 分 | 锚点（官方 B1 量表 · 中文转述） |
|---|---|
| 5 | 尽管有些犹豫，仍能产出**成段**的语言；内容相关（**允许有一些重复**）；用**一系列**衔接手段 |
| 4 | 介于 3 档与 5 档之间（官方偶数档口径：与相邻两档特征混合） |
| 3 | 尽管有犹豫，回答仍**超出短句**；内容**大体相关**（可能有些重复）；用**基础**衔接手段 |
| 2 | 介于 1 档与 3 档之间（同上） |
| 1 | 回答以**短句**为主、犹豫频繁；**重复已知信息或跑题** |
| 0 | 低于 1 档的表现 |

### B2（FCE）

| 分 | 锚点（官方 B2 量表 · 中文转述） |
|---|---|
| 5 | **很少犹豫**地产出成段语言；内容相关，**思路组织清楚**；用一系列衔接手段**与话语标记** |
| 4 | 介于 3 档与 5 档之间（官方偶数档口径：与相邻两档特征混合） |
| 3 | 尽管有些犹豫，仍能产出成段语言；内容相关，**重复很少**；用一系列衔接手段 |
| 2 | 介于 1 档与 3 档之间（同上） |
| 1 | 尽管有犹豫，回答仍**超出短句**；内容大体相关（**允许有一些重复**）；用**基础**衔接手段 |
| 0 | 低于 1 档的表现 |

**必查三项**（是上面官方判据的落地抓手，不是另一套标准）：

1. **切题**：官方每一档都要求"内容相关"（3 档：大体相关；5 档：相关 + 思路组织清楚）。逐句核"是不是在回答问句问的那件事"、二选一题有没有给出偏好。**跑题与重复已知信息是官方 1 档的判据**，单句漏答不足以把人压到 1 档。
2. **展开程度**：官方 3 档的判据是"回答超出短句"，5 档是"成段语言"。词数只是佐证——出现 3 词以下的答案（如 `No, I didn't.`）是"仍在短句层"的证据。**"B2 每题 30–50 词"是教学经验值，官方没有词数门槛**，别当官方线用。
3. **衔接手段的层级**：B1 的 5 档要"一系列"、3 档只要"基础"；B2 的 3 档就要"一系列"。只会用 `because` 和 `and`，在 B2 是 1 档的量级、在 B1 落在 3 档；有没有 but / although / so / for example / actually，就是"基础"与"一系列"的分界。

**流利度指标放在本维度**（不是发音）：官方把犹豫写在话语组织里——5 档"很少犹豫"、3 档"尽管有些犹豫"、1 档"犹豫频繁"。所以犹豫是官方判据，但**只有"频繁犹豫"才往下压档**，偶有犹豫不构成扣分。量化抓手：语速（词/分）、停顿次数与位置、≥1 秒的长停顿、填充词、自我纠正次数。参考区间：B2 顺畅表达约 120–150 词/分，这是**教学参考值（非官方）**；**语速高低本身不直接扣分**，要看它是否伴随"内容讲不完""逻辑断裂"。

## 三、发音 Pronunciation

**来源**：以下锚点转述自 Cambridge 官方 Speaking assessment scales 的"发音 / Pronunciation"一栏——A2 Key for Schools 手册 p45、B1 Preliminary for Schools 手册 p64、B2 First for Schools 手册 p82。官方这一栏的判据是固定的四件事：**可懂度（intelligibility）、语调、句重音与词重音、个别音**；官方 A2 量表只到"可懂度 + 话语层面与词层面的发音特征"两条，**没有**重音与语调。下面按这个结构分级排。官方英文原文为准，本节是教学用中文转述。

### A2（KET）

| 分 | 锚点（官方 A2 量表 · 中文转述） |
|---|---|
| 5 | **大体听得懂**；在**话语层面与词层面**都有一些发音特征的控制 |
| 4 | 介于 3 档与 5 档之间（官方偶数档口径：与相邻两档特征混合） |
| 3 | **大体听得懂**，尽管发音特征的控制有限 |
| 2 | 介于 1 档与 3 档之间（同上） |
| 1 | 发音特征的控制很有限，**常常听不懂** |
| 0 | 低于 1 档的表现 |

A2 不把语调、重音单列成判据——别拿 B1 / B2 的那几条去压 A2 作业。

### B1（PET）

| 分 | 锚点（官方 B1 量表 · 中文转述） |
|---|---|
| 5 | **听得懂**；语调**大体**恰当；句重音与词重音**大体**放准；个别音**大体**发清楚（四条都带"大体"） |
| 4 | 介于 3 档与 5 档之间（官方偶数档口径：与相邻两档特征混合） |
| 3 | **大体听得懂**；话语层面与词层面的发音特征**有一些**控制（判据只到这两条） |
| 2 | 介于 1 档与 3 档之间（同上） |
| 1 | **仍然大体听得懂**，只是发音特征的控制有限 |
| 0 | 低于 1 档的表现 |

### B2（FCE）

| 分 | 锚点（官方 B2 量表 · 中文转述） |
|---|---|
| 5 | **听得懂**；语调**恰当**；句重音与词重音**放准**；个别音**发清楚**（四条都是确定表述，不带"大体"） |
| 4 | 介于 3 档与 5 档之间（官方偶数档口径：与相邻两档特征混合） |
| 3 | **听得懂**；语调**大体**恰当；句重音与词重音**大体**放准；个别音**大体**发清楚 |
| 2 | 介于 1 档与 3 档之间（同上） |
| 1 | **大体听得懂**；话语层面与词层面的发音特征**有一些**控制（与 B1 的 3 档、A2 的 5 档同句） |
| 0 | 低于 1 档的表现 |

**判 1 档之前先看这一条**：B1 / B2 的 1 档原文都是"大体听得懂，只是发音特征的控制有限"，**只有 A2 的 1 档才写"常常听不懂"**。所以"有口音、听得出是外国学习者"不构成 1 档，B1/B2 判 1 档要真能指出"听不懂"的证据。

**官方另有一句说明文字**（出自手册的口语说明，不是量表描述词）：**不需要有英语母语口音，清楚就行**。所以口音本身不扣分，扣分的是听不懂。

**AI 不给这一项的分。** AI 只能产出"抽听点位表"（时间戳 + 转写原文 + 疑点原因）。发音分有两个合法来源：

1. **语音评测引擎自动给**（讯飞 ISE），此时必须标注"语音评测引擎（非官方考官分）"，并注明只覆盖念题部分；
2. 引擎不可用时**标 `待教师填`**，由教师听点位后给分。

引擎原始分 → 0–5 的映射阈值见第五节的 `to_band()` 表；**映射只是教学口径，不是官方换算表**。

**教师给分时的三个抓手**（对应官方那几条判据，用来定位档位）：

- **个别音**（官方 individual sounds）：/θ/ /ð/、/v/ vs /w/、词尾 -s（清化/漏读）、-ed 结尾、多音节重音位置。
- **词级清晰度**（官方"词层面的发音特征"与词重音）：音节边界是否交代清楚（典型信号：一个词被听成几个常用词）。
- **语调**（官方 intonation）：句尾是否降调、疑问句是否升调、从句结尾是否收住；**A2 不按这两条判**。

## 四、互动交际 Interactive Communication

**只在有对手方的录音上评。独白 / 自问自答作业一律 `N/A` 并写明原因。**

**来源**：以下锚点转述自 Cambridge 官方 Speaking assessment scales 的"互动交际 / Interactive Communication"一栏——A2 Key for Schools 手册 p45、B1 Preliminary for Schools 手册 p64、B2 First for Schools 手册 p82。官方英文原文为准，本节是教学用中文转述。4 / 2 档按官方偶数档口径写（见本文件开头"读锚点表之前"）。

### A2（KET）

| 分 | 锚点（官方 A2 量表 · 中文转述） |
|---|---|
| 5 | 能维持**简单交流**；**几乎不需要**对方提示与支持 |
| 4 | 介于 3 档与 5 档之间（官方偶数档口径：与相邻两档特征混合） |
| 3 | **有些吃力，但**仍能维持简单交流；**需要**对方提示与支持 |
| 2 | 介于 1 档与 3 档之间（同上） |
| 1 | 维持简单交流**相当吃力**；**需要更多**提示与支持 |
| 0 | 低于 1 档的表现 |

A2 的判据只有两条——能不能维持简单交流、需要多少提示与支持；**没有**"主动发起次数 / 话轮长度"这类要求，别拿它们压 A2 作业。

### B1（PET）

| 分 | 锚点（官方 B1 量表 · 中文转述） |
|---|---|
| 5 | 能恰当**发起与回应**；能**维持并发展**互动、最终**谈出一个结果**，且对方**几乎不需要**给支持 |
| 4 | 介于 3 档与 5 档之间（官方偶数档口径：与相邻两档特征混合） |
| 3 | 能恰当发起与回应；**几乎不需要**提示与支持就能让互动继续 |
| 2 | 介于 1 档与 3 档之间（同上） |
| 1 | **有些吃力，但**仍能维持简单交流；**需要**提示与支持 |
| 0 | 低于 1 档的表现 |

### B2（FCE）

| 分 | 锚点（官方 B2 量表 · 中文转述） |
|---|---|
| 5 | 能恰当发起与回应，并**接上其他人说过的话**；能维持并发展互动、最终**谈出一个结果**（这一档不再限定"只需很少支持"） |
| 4 | 介于 3 档与 5 档之间（官方偶数档口径：与相邻两档特征混合） |
| 3 | 能恰当发起与回应；能维持并发展互动、最终谈出一个结果，且**只需很少支持** |
| 2 | 介于 1 档与 3 档之间（同上） |
| 1 | 能恰当发起与回应；**只需很少提示与支持**就能让互动继续（与 B1 的 3 档同句） |
| 0 | 低于 1 档的表现 |

**看什么**（用来定位落在上面哪一档）：主动发起次数、是否提出过问题、回应延迟（沉默多久）、是否承接对方用词、话轮长度是否失衡。

**判档前先回到官方那一句**：B1 / B2 的 1 档原文仍然是"能恰当发起与回应 / 只需很少提示与支持就能把互动继续下去"。也就是说，**"回答偏短、较少主动发起、常需对方推动"是 B1 / B2 的 1 档，不是 3 档**——3 档的门槛是"恰当发起与回应 + 几乎不需支持就能继续"（B2 的 3 档还要求"维持并发展互动、谈出结果"）。"几乎不参与、交流中断"已经低于 1 档：有录音证据就判 0，只是没录到对手方就标 `N/A`，症状听不清就标 `证据不足`。

## 五、官方分制

### 5.1 评分结构（引自 Cambridge《The Cambridge English Scale explained》）

| 级别 | 考官评的维度 | 权重 | 主考官(interlocutor) | 口语原始满分 |
|---|---|---|---|---|
| **A2 Key / for Schools** | 语法与词汇、**发音**、互动交际 —— **只有 3 项，没有话语组织** | 每项 ×2 | Global Achievement ×**3** | **45** |
| **B1 Preliminary / for Schools** | 语法与词汇、话语组织、发音、互动交际 | 每项 ×**1**（不翻倍） | Global Achievement ×**2** | **30** |
| **B2 First / for Schools** | 同上 4 项 | 每项 ×**2** | Global Achievement ×**4** | **60** |

### 5.2 计算方式

```
B2 First：       (四项之和 × 2) + (Global Achievement × 4) → /60
B1 Preliminary： (四项之和 × 1) + (Global Achievement × 2) → /30
A2 Key：         (三项之和 × 2) + (Global Achievement × 3) → /45
```

补充官方规定：

- **允许半分**（Examiners may award half marks）。
- **没有单项最低分要求**，成绩按整体表现判定。
- 除分析性评分外，主考官另给 **Global Achievement**（整体表现，0–5）——它是第五个独立分数，不是四项的平均值。**Global Achievement 只在完整模拟时才给**（见第六节），单篇作业没有这个语境。
- 每个技能（读/写/听/说）单独报在剑桥量表上。
- **原始分 → 剑桥量表分（如 160）的换算表只对官方练习卷有效，官方明确说不能用来预测真实考试分数**。换算表在官方 PDF 里是图片；本 skill 不覆盖换算，也不得自行编造。

### 5.3 引擎原始分 → 教学 0–5（`to_band()` 唯一实现）

教学映射阈值（全 skill 唯一一份，写在 `scripts/kpf_xfyun.py` 的 `to_band()`，其他脚本 import 它）：

| 引擎原始分（0–100） | 教学映射 |
|---|---|
| ≥90 | 5 |
| 80–89 | 4 |
| 70–79 | 3 |
| 60–69 | 2 |
| <60 | 1 |

引擎取不到分（返回 None）时输出 `—（未取得）`，**不得**当作 0 分、**不得**映射成 1 分。

### 5.4 得分率参考线（**教学经验值，非官方**）

仅在完整模拟（第六节 6.2）里用于"参考判定"：

| 得分率 | 参考判定 |
|---|---|
| ≥80% | 明显高于合格线，可冲更高等级 |
| 70–79% | 稳过 |
| 60–69% | 合格线附近，需确认 |
| <60% | 目前未达该级别合格水平 |

## 六、给分口径：单篇作业 vs 完整模拟

### 6.1 单篇作业只给分项分

| 场景 | 给什么 | 不给什么 |
|---|---|---|
| **单篇作业**（一页 / 一次录音 / 只覆盖部分题型） | **每个维度单独的分**（0–5，可半分）+ 各维度证据 | ❌ 加权总分 ❌ 得分率 ❌ 换算量表分 ❌ 过没过判定 ❌ Global Achievement |
| **完整模拟**（覆盖全部 Part，四项齐备） | 分项分 + 加权总分 + 得分率 + 参考判定 | ❌ 换算量表分 |

**理由**：一页 Part 1 问答只测了口语的一部分，四项里还常缺互动交际。用它算 /60 总分并判"过没过"，是把局部表现当成整体成绩，会误导家长。

**单篇作业的标准写法**（照此写，不要自创）：

```
一、本次评分（参照 <级别> 口语评分标准，各维度 0–5 分）

语法与词汇：1 / 5
话语组织：2 / 5
发音：5 / 5
互动交际：待补（本次是独自录音，测不到和别人的对话能力）

这是单次录音的表现，不作为考试总分预估。
```

- A2 Key 作业**不写"话语组织"这一行**（该级别无此维度）。
- 最后那句免责说明**必须写**，一字不改。
- 教师若确实想要总分预估，需在覆盖全部题型的完整模考后再算。

### 6.2 完整模拟才给总分与判定

覆盖全部 Part、四项（A2 为三项）齐备时：

1. 逐项给 0–5（可半分），标注评分方；
2. 按 5.2 的官方权重算加权原始总分与得分率；
3. 按 5.4 给出参考判定，并写明"参考合格线为教学经验值"。

**互动交际缺失时**（独自录音）：只给「可评维度的参考分」，并附一张「补上互动交际后的总分对照表」（按 2 / 3 / 4 分三种情形各算一行），教师补分后即可定稿。此时仍属单篇口径，**不得**直接判"过没过"。
