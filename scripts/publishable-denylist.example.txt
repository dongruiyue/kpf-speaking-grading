# 这个文件是示例，仓库里只放它。真正要拦的姓名/班号属于你自己的学生信息，
# 所以私有黑名单不住在仓库里，而是放在仓库外的固定位置：
#
#     ~/.kpf-speaking/publishable-denylist.txt
#
# scripts/check_publishable.py 的查找顺序：
#   ① ~/.kpf-speaking/publishable-denylist.txt    （存在就用它）
#   ② 本文件                                       （仓库内示例，作为兜底）
#
# 于是：单纯克隆仓库的人什么都不用配；有真实学生的使用者把名单写进 ①，
# 那份名单就永远不会跟着仓库被提交出去。闸门还会检查仓库里**没有**
# 叫 publishable-denylist.txt 的文件（有就是私有黑名单被误提交了）。
#
# 格式：一行一条，`#` 开头是注释，空行忽略，大小写敏感。
