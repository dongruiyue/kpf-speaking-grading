# 讯飞接入指引（发音分的来源）

## 为什么这一步要你自己动手

本 skill **不给发音分**——AI 不许自己编发音分，这是硬规矩（`references/03-scoring-rules.md` 第六节）。
发音分只有两个来源：

1. **语音评测引擎**（讯飞），或
2. **老师听点位后手填**（`发音.md` 里会给你一张带时间的抽听点位表）。

**讯飞是国内首选**：免信用卡、免代理、有免费额度，而且它独有「句末语调」和「逐词得分」——
"这一句该降调他念成了升调"这种错，纯人工听音很容易漏。

本指引就把"额外要做的那几步"讲全：**开哪个服务、抄哪三个字段、怎么填、怎么验、报错怎么查、额度怎么省。**

> 全程离线能做完的部分：填 config、跑 `make doctor`。
> 只有最后"验证一次"会消耗额度（1 次，见第四节）。

---

## 一、先弄清开哪一个：两个讯飞产品，用途完全不同

**两个里只有一个决定发音分**：`suntone` **要开**（发音分的首选来源），流式版可选（只作质检）。

| 控制台里的名字 | 本 skill 里谁在用 | 干什么 | 要不要开 | 免费额度 |
|---|---|---|---|---|
| **语音评测 suntone**（页内显示「声通中文评测API」） | `scripts/kpf_xfyun.py` | **主评分**：overall / 发音 / 韵律 / **句末语调** / 逐词和音素得分 | **要开**（发音分的首选来源） | 作者控制台实测 **1000 次** |
| **语音评测（流式版）** | `scripts/kpf_ise_stream.py` | 只作**质检**：乱读拒识、音频质量诊断 | 可选 | 作者控制台实测 **500 次** |

额度与菜单名以**你的**控制台为准；上面是作者开通时看到的数字。

### ⚠️ 两个评测引擎绝不能混用出分

同一条录音，suntone 与流式版的总分**实测能差 18 分**，映射到 0–5 档能差两档。
原因是流式版按「**无中式口音**」打分，与剑桥的评分理念不合，**会系统性压低分数**。

所以本 skill 的约定是：**suntone 出分，流式版只用来问"这段音频是不是读得太烂/太吵"**。
两者的实测差异记在 `references/06-verification.md` 第四节之二、四之三。

## 二、开一个应用：5 步

1. **注册**：<https://console.xfyun.cn>（手机号 + 邮箱）。
2. **实名认证**：按控制台提示走个人认证即可。**没认证时部分服务开不了**，这一步别跳。
3. **创建应用**：控制台里「创建应用」，名字随便起，建议一眼能认出来
   （作者的叫「剑五口语语音评测」——你自己看到的名字会出现在后面的服务页标题上，别起成一串乱码）。
4. **开通服务**（最容易漏、也是"接口直接报错"的头号原因）：
   控制台左侧「**语音扩展**」→ 找到「**语音评测suntone**」→ 点**开通**。
   - 菜单名可能随控制台改版，找不到就在左侧搜索「语音评测」
   - **不开通的表现不是"没反应"，而是证书没问题、接口直接返业务错误码**（对照表见第六节）
5. **抄三个字段**：开通后那一页右侧有「**WebSocket 服务接口认证信息**」：

   | 控制台字段 | 填到 config 里的键 |
   |---|---|
   | `APPID` | `xfyun.appid` |
   | `APIKey` | `xfyun.api_key` |
   | `APISecret` | `xfyun.api_secret` |

   页面下方还会给一条「声通中文评测API 接口地址」
   `ws(s)://cn-east-1.ws-api.xf-yun.com/v1/private/s8e098720` —— **这个不用你填**，脚本已内置。

   > 控制台把服务显示成「声通中文**评测**API」只是**显示名**；官方文档里它是「**中英文**评测」。
   > 所以**传 `lang=en` 就是评英文**，脚本默认就是 `lang=en`。别因为名字里带"中文"以为不能评英文。

## 三、填进 `config.json`

```bash
mkdir -p ~/.kpf-speaking
cp config.example.json ~/.kpf-speaking/config.json     # config.example.json 在仓库根目录
$EDITOR ~/.kpf-speaking/config.json
```

只填 `xfyun` 块，别的块全部留空也能跑：

```json
"xfyun": {
  "appid": "你的 APPID",
  "api_key": "你的 APIKey",
  "api_secret": "你的 APISecret"
}
```

### 常见填错（按踩坑频率排）

- **复制时带上了首尾的引号或空格**。APIKey 通常是一长串十六进制，**直接粘**就好。
- **三个字段搞混**。对应关系是 `APPID↔appid`、`APIKey↔api_key`、`APISecret↔api_secret`，三个名字长得像。
- **三个字段不是同一个应用的**。它们必须来自**同一个**应用，混用会在握手阶段就失败。
- **端点要覆盖**：如果你的控制台给的不是 `cn-east-1`，在 xfyun 块里加 `"host"` 和 `"path"` 两个字段覆盖默认值。
- **别把 key 提交进任何 git 仓库**。`config.json` 在仓库外（`~/.kpf-speaking/`），仓库的 `.gitignore` 也挡住了 `config.json`。

## 四、验证：第一次一定只花 1 次额度

别一上来跑整页。**造一个只含 1 句的题库**，一次只花 1 次：

```bash
# 1) 先离线自检：config 齐不齐、题库/依赖有没有问题（不联网、不花额度）
make doctor

# 2) 再用 1 句试真打通（消耗 1 次）
echo "What kind of music do you listen to in your free time? Why?" > /tmp/one.txt
.venv/bin/python scripts/kpf_pronounce.py work/<日期>-<学生>/<文件名>--local.json \
    --provider xfyun --questions /tmp/one.txt --out /tmp/发音-test.md
```

**成功的样子**（stderr）：

```
[ise] 发送第 1/38 帧（status=0）
[ise] 收到第 1 帧 code=0 status=0
已写出 /tmp/发音-test.md（provider=xfyun）
发音预估 4 / 5（来源：语音评测引擎（讯飞 ISE，非官方考官分；只念题部分））
```

**只看一个词：`provider=xfyun`。** 看到它 = 通了。
看到 `[降级]` = 没通，原因就在那一行里，对照下一节。

> **`--questions` 是必给的**：讯飞是**朗读型**接口，必须有参考文本（`refText`），它评的是**念题部分**。
> 缺了会明确降级到本机疑点模式——不会静默给 0 分，但也就没有发音分了。

## 五、省钱：额度怎么算

- 计费单位是**句**。一页 5 题（念题 5 句）= **5 次**；1000 次大约够 **200 页**作业。
- **题库文件只放念题，别把答案也写进去**——脚本按行切分，多一行就多一次调用。
- 一页跑一次就够。结果可复现（作者实测同一段音频两次跑出 100% 相同的总分），不必反复重跑。
- 免费额度用完可在控制台购买。**拿不到分时脚本会明确报错并 `exit 1`，绝不伪装成分数**——
  这是刻意的（上一版曾经把"没拿到分"渲染成 `1 / 5`，已修）。

## 六、报错对照表

`[降级] <provider> 不可用 —— <原因>` 这一行会原样带出根因，逐条对照：

| 你看到的 | 原因 | 怎么办 |
|---|---|---|
| `…config.json 里的 xfyun 缺少字段：api_secret` | config 没填全，或键名拼错 | 三个字段照抄填全 |
| `讯飞评测需要参考文本：请加 --questions …` | 没给题库 | 加 `--questions <题库.txt>` |
| `找不到原始音频：…` | 转写稿 `meta.file` 指向的音频不在本机 | 加 `--media <音频路径>`，或把音频放回原路径 |
| `题目文件里没有内容：…` | 题库文件是空的 | 一行一题，UTF-8 |
| `header.code=10106 wrapper output data invalid(key or type)` | 请求体缺 `parameter.st.result` 块 | 脚本已内置修复；还报就是版本旧，更新仓库 |
| `header.code=10163 unknown field` | `result` 放错了层级 | 同上 |
| 握手阶段就断 / 401 / 服务端不回任何帧 | ① 服务**没开通** ② APPID 与 key 不是同一个应用 ③ **实名认证没做** | 回控制台逐项核第二节 |
| `[降级] xfyun 不可用 …` 后接 `[降级] local …` | 讯飞没配好，链子在往后降（正常行为） | 看前面那条 xfyun 的原因 |
| 全部降级 → `provider=manual` | 没有任何可用引擎 | 发音分由老师手填（`发音.md` 里有抽听点位表） |

## 七、不想开任何服务，也能跑完整流程

发音维度标「待补」，家长版第六段写明"发音本次未评"，其余流程照旧。家长版里那一栏由老师填。
这正是 `references/03-scoring-rules.md` 第六节要的效果：**AI 不许自己编发音分**。

## 八、还有一处会用到讯飞：题库

`--questions` 的题库要**你自己建**（一行一题）。仓库 `questions/` 里那两份是剑桥教材的真题题干，
只作格式示例、有版权（见 `questions/README.md`）。请优先用自己教材或自己编写的题目。
