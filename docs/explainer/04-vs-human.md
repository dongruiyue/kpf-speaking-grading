# 04 · 与人工批改的对比：谁是主角，谁干什么活

> 上一篇：`03-usage.md`（使用方法）· 下一篇：`05-accuracy-and-roadmap.md`（准确度与待改进项）
> 本篇的所有数字都有出处；判档准确度的原始数据在 `docs/calibration.md`。

## 一、先给结论

**它不替代老师。它替代的是批改里那五件机械活：**

1. **听写誊录** —— 把音频变成可检索的文本，并按题切开。
2. **算指标** —— 每题词数、答段秒数、语速、停顿次数、最长停顿、低置信度词点位。
3. **找证据** —— 每个分数下面配 2–3 条原句或数字。
4. **套模板** —— 内部记录 / 家长版 / 学生版三份结构，一次成型。
5. **查格式** —— 禁用词、技术指标、免责句、维度齐备、有没有编造原句。

**老师仍然负责的六件事（机器做不了，也不该做）：** 听发音、判互动交际、判断语义崩坏是否属实、判断情绪与态度、决定"跟这个家长怎么说"、复核机器判错的地方。

一句话：**机器出初稿，人定稿。**

## 二、判档准确度的真实数字（先看这个，再看别的）

拿剑桥官方公开样题视频 + 配套官方给分文件当外部真值（6 个 case、16 个可比维度点；发音点因为是对话考试、朗读型接口用不上，全部是 AI 缺值）：

| 口径 | 完全一致 | ±1 档以内 | 整体偏差 |
|---|---|---|---|
| **真盲判档**（只看量表、不知道官方分） | **3/16 = 18.8%** | 15/16 = 93.8% | **−0.47 档（偏严）** |
| 非盲判档（判官已知官方分） | 14/16 = 87.5% | 16/16 = 100% | −0.06 |
| 真盲判档、**剔掉 2 个证据不足的点** | 3/14 = 21.4% | **14/14 = 100%** | −0.36 |

**先看第三行怎么来的**：16 点里有 2 点是 A2 的互动交际，判据要求"考官提示了几次、沉默了多久"，而判官手里只有纯转写 —— 按本流程自己的纪律，这两点本该标 `待补`，却进了统计。剔掉之后，**唯一掉出 ±1 档的那一点也一起消失了**（±1 档因此变成 100%）。

三行合起来读，才看得到真正的短板：

- **±1 档 93.8%，剔掉证据不足的点是 100%** —— "差出相邻档"这件事只发生在证据不足的那两点上。
- **完全一致只有 18.8%，剔掉证据不足的点几乎不动（21.4%，分子没变）** —— 因为**那 3 个"完全一致"的命中全部来自互动交际**（官方 5 → AI 5）。
- **AI 真正负责、也真正有证据的两项（语法与词汇 + 话语组织）是完全一致 0/10**：10 个点全部差半档或一档，方向一律偏严。**所以"18.8%"这个数不能读成"它挺准"。**

第一、二行的差距（18.8% vs 87.5%）是**锚定效应**，不是"非盲那轮变准了"：它说明量表描述与官方档位是**兼容**的（知道目标档就能自圆其说），但不说明它**独立判档**可靠。

**没有对"老师本人 vs 官方"做过同口径测量**——所以不能说"它比老师差多少"。能说的是：**它现在的判档精度不足以独立定档，只适合当老师的第二意见或初稿。**

## 三、逐维度分工

| 维度 | 机器能做到什么 | 人工必须做什么 |
|---|---|---|
| **语法与词汇** | 逐句错误清单 + 升级用词；可给 0–5 预估（**已知转写会"顺手改对"学习者的错误，所以偏宽的方向存在、幅度未测**） | 复核被"顺平"的错误；决定哪些错误值得写进反馈 |
| **话语组织** | 切题 / 展开 / 衔接 / 流利度指标，可给 0–5 预估 | 判断"答得短"是不是任务本身要求的（A2 只要求简单交流） |
| **发音** | **只能定位疑点**：带时间戳的抽听点位表（依赖词级置信度，且只能两个引擎互证） | 听音频定档；或走讯飞语音评测拿分。**AI 一律不给发音分** |
| **互动交际** | 只在有对手方的录音里能提供线索 | 定档。独白 / 自问自答一律 `N/A`；**A2 的互动交际在纯转写里基本测不到**（看不到考官提示几次、沉默了多久） |

## 四、三栏对照：人工 / 裸模型 / 本流水线

| 能力 | 人工老师 | 裸模型（一次 prompt） | 本流水线 |
|---|---|---|---|
| 听发音 | 可以 | **不行**（手里只有文字） | 交语音评测引擎；AI 只出疑点表 |
| 判互动交际 | 可以（有对手方时） | 会给一个分 | 有对手方才有证据，独白标 `N/A` |
| 口径稳定 | 会漂（同错换说法） | 每换一次对话就漂 | 规则在文件里，14 项断言盯漂移 |
| 速度 | 一晚上 5 个人 | 快 | 一页约 1 分钟（转写 + 分析） |
| 证据可溯 | 靠记忆 | 常无证据，或编原句 | 每分配 2–3 条证据；引用原句必须能在转写里找到 |
| 防编造 | 不会编 | **会编**（尤其"学生原话"） | 相似度 < 0.85 直接判 error |
| 格式合规 | 靠自制 | 不保证 | 退出码把关，不合规不许交付 |
| 判档精度 | 有教学经验，但**未做过同口径测量**（不要写成"老师更准"） | 未知且不可复核 | 完全一致 18.8%、±1 档 93.8%，**偏严 −0.47**；**剔掉 2 个证据不足的点后 ±1 档 100%、偏差 −0.36，而它真正负责的两维是完全一致 0/10** |
| 判断分寸（怎么跟这个家长说） | 强 | 会写出正确但冷冰冰的话 | 只给结构，最后一段必须人写 |
| 沉淀（错误卡 / 班级共性卡） | 靠笔记习惯 | 无 | 固定产物，跨批次可比 |

**读这张表要抓住的差别**：裸模型输的不是"聪明"，是**没有标尺、没有证据链、没有闸门**。本流水线的价值不在生成，在于把随机性限制在"措辞"这一层。

## 五、人工不可替代的六件事（逐条说明为什么）

1. **听发音。** 转写文本里没有音频。这是硬件级的信息缺失——所以 AI 的发音输出被限制成"点位表"，不是分。
2. **判互动交际。** 判据是"能不能维持交流、需要多少提示和支持"，而切分后的文本**看不到考官提示了几次、沉默多久**。
3. **判断语义崩坏是否属实。** 脚本能标出"考官听不懂的句子"，但那到底是学生原话还是转写听错，**只有听一遍才知道**。这一条影响很大（会进错误卡和家长反馈）。
4. **情绪与态度类判断。** "畏难""不敢说""上课不专心"这类结论不能从音频推出，只能来自老师的课堂观察或回访表。
5. **决定措辞的分寸。** 参数化的模板可以保证不违规，但"这个家长这次只能提两条问题"这种判断是人的。
6. **复核机器判错的地方。** 考虑到判档偏严半档、转写会改对错误，**人是最后一道防线**——尤其是明显反常的分数（全班都 4–5 分时突然出现 2 分）。

> 这六条是**能力层面**的分工；落到每次批改的具体动作，就是 `03-usage.md` 第六节那五步（判断作业形态 → 索要图片 → 改措辞 → 定互动交际 → 过闸门）。主 `README.md` 把它们概括成"老师只做两件事"，说的是同一件事的粗粒度版本。

## 六、什么时候别用它

- 你要的是**考官式定档**：现在做不到（见第二节）。
- 你要**预测考试总分**：官方明确说口语原始分推不出总分。
- 录音里**只有学生一个人**，却要评互动交际：换一次两两对话再批。
- 作业是**图片类题型**而你拿不出图片：描述完整性无法评估，只能评语言层面。
- 你想顺手做**声纹/身份判断**：能力之外，别指望。

## 七、分工之后，老师的时间花在哪

流水线跑完之后，老师剩下的动作只有五个（`03-usage.md` 第六节）：判断作业形态、要图片、改措辞、定互动交际、过闸门。

**这五件事的时间，才是这套东西真正要替老师省下来的时间**——前面那些机械活不是"省掉了"，是"再也不用想了"。
