# 05 · 准确度账与待改进项

> 上一篇：`04-vs-human.md`（与人工批改的对比）· 回到 `README.md`（索引与讲稿）
> 这一篇是全套材料里最不讨好、也最该讲的一篇。数字都有出处：`docs/calibration.md`（方法与四轮结果）、`references/06-verification.md`（实测结论与已知坑）。

## 一、怎么给自己量尺寸

校准的办法只有一种：**拿有外部真值的语料，让 AI 独立判档，再和真值比。**

- **真值来源**：剑桥官方发布的**公开样题视频 + 配套官方给分文件**（考官真实给分，公开可核）。
- **语料规模**：6 个 case / 16 个可比维度点 —— FCE(B2) 两位、KET(A2) 两位、PET(B1) 两位考生。发音点全部是 AI 缺值（对话考试，朗读型接口用不上），不计。
- **盲判纪律**（这几条是踩坑之后定死的）：
  1. 判档必须在**看到官方分之前**完成 —— 先写 `ai-分项.json`，判完再写 `teacher.json`；
  2. 用**隔离目录**、姓名换成占位符；
  3. 每轮**换一个全新判官实例**，上一轮产物挪出隔离目录；
  4. **判官读的量表必须是净化版副本**——量表里只要写着官方分或历轮结果，判官读到量表就读到了答案。

第 4 条是最狠的一条，也是被实证撞出来的：**第 2、3 轮就是这么坏的**——那两轮的量表里写着"三位被考官全给 5""11 个点是 5 档""中段轨迹 3 → 1.5 → 3.5"，判官不用推理就知道该往哪儿靠。**换判官、抹姓名、挪旧报告，都堵不住这条路。**

## 二、四轮结果（只有两轮是真盲）

| 轮次 | 用哪版量表 | 真盲？ | 完全一致 | ±1 档 | 整体偏差 |
|---|---|---|---|---|---|
| 一 | 旧版 | **是** | 2/16 = 12.5% | 14/16 = 87.5% | −0.88 |
| 二 | +5 档锚点 | **污染**（量表泄漏答案） | 6/16 = 37.5% | 15/16 = 93.8% | −0.34 |
| 三 | +中段修正 | **污染**（量表泄漏答案） | 8/16 = 50.0% | 16/16 = 100% | −0.06 |
| **四** | **现行量表** | **是** | **3/16 = 18.8%** | **15/16 = 93.8%** | **−0.47** |

口径提醒：`±1 档` **包含**完全一致（0 与 ±0.5 都算在里面），**不能与"完全一致"相加**。

**唯一可比的对比是真盲一 ↔ 真盲四**（旧量表 → 现行量表）：完全一致 12.5% → 18.8%、偏差 −0.88 → −0.47、掉出 ±1 档的点 2 → 1。**但这只能读成"本轮复测指标有改善"，读不成"改动确实有效"**：四个真盲轮每轮只有一个判官实例、而且互不相同，"改动起效"与"这一轮判官手松/手紧"分不开。能确定的是另一半：**37.5% / 50.0% 是被泄漏撑起来的，不是量表的功劳。**

**对外基线就是第四轮：18.8% / 93.8% / −0.47 —— 但这个数字对"证据口径"敏感，下面单独说。**

### 把证据不足的点剔掉之后（口径敏感性）

16 点里含 **2 个证据不足的点**：C / D 属 A2，它们的**互动交际**判据需要"考官提示了几次、沉默了多久"，而判官手里只有纯转写 —— 按本流程自己的纪律，这两点本该标 `待补`，却照样进了统计。三组口径：

| 口径 | 可比点 | 完全一致 | ±1 档 | 平均带符号差 |
|---|---|---|---|---|
| 全部（对外基线） | 16 | 3/16 = 18.8% | 15/16 = 93.8% | −0.47 |
| 剔除 A2 互动交际 2 点 | 14 | 3/14 = 21.4% | 14/14 = **100.0%** | −0.36 |
| 剔除全部互动交际 6 点 | 10 | **0/10 = 0.0%** | 10/10 = 100.0% | −0.45 |

**三行一起读，才会看到真正的短板：**

- **±1 档 93.8% → 100%**，靠的是剔掉**唯一一个掉出 ±1 档的点** —— 那唯一一处例外，正好落在证据不足的维度上。
- **三个"完全一致"的点全部是互动交际点**（官方 5 → AI 5）。
- **AI 真正负责、也真正有证据的两个维度（语法与词汇 + 话语组织）是完全一致 0/10**：10 个点全部差半档或一档，**方向一律偏严**。**产品声称能给的那两项，恰好是完全一致率 0 的那两项。**

（B1 / B2 的互动交际点仍留在统计里：这两个级别的判据含"发起与回应 / 发展互动 / 谈出结果"这类**在文字里看得见**的成分，只有"需要多少支持"那一半证据受限。这一点记为**下一个待测量的口径**。）

## 三、必须和数字一起读的六个边界

1. **样本严重偏上。** 16 个官方分点**全部落在 3–5 档、0 个落在 0/1/2 档**。所以四轮验证的只是"3–5 档这一带对得上"。而实际带的学生多在 **1–3 档** —— **低档（0–2）没有任何外部验证**。
2. **语法与词汇另有已识别的转写偏差，方向与幅度都未测量。** 本机 whisper 会自动把学习者的错误改对（实测：官方评语引用的原句含三处错误，转写把它们改成了正确形式）。所以转写比真实口语更"正确"，它对一致率的影响**可能美化、也可能加大偏差**。
3. **发音维度 0 校准。** 官方样题是对话考试，而讯飞 ISE 是朗读型接口、必须有参考文本。发音点全是"AI 缺值"。
4. **锚定效应已实测。** 同一批语料：知道官方分 87.5%，不知道 12.5% / 18.8%。**判档必须在看真值之前完成**，判官读的表必须已抹数字。
5. **绿灯 ≠ 判分可用。** 校准器 `±1 档` 的 80% 门槛太松：真盲一轮整体偏低 0.88 档、有 11 条差 ≥1 档，**却仍然算"绿灯"**。**主指标应当是"完全一致率"与"系统性偏差"**，±1 档只是"相邻档分歧在教学上能否接受"的旁证。
6. **证据口径会改变结论。** 见上面「把证据不足的点剔掉之后」：剔掉 A2 的 2 个点后 ±1 档 93.8% → 100.0%、偏差 −0.47 → −0.36；**剔掉全部互动交际后完全一致率是 0/10**。所以**报数时必须写明"哪些点有充分证据"** —— 边界 5 说"完全一致率才是主指标"，在扣掉互动交际之后，这个主指标是 **0%**。

再叠四条方法学限制：**每轮只有 1 个判官实例**（n = 1，只能看方向、不能当精度指标）、**语料没换过**（同 6 条反复用，不是多批独立样本）、**低档与发音零覆盖**、**任何写进量表的校准数字都会污染盲判**。

## 四、已识别的坑（除校准之外）

| 坑 | 现象 | 现状 |
|---|---|---|
| 小模型不可用 | `tiny` 对学习者语音对齐度 **0%** | 已写死要求 `large-v3-turbo` 或更大 |
| 转写会把错误"顺"平 | `he go` → `he goes`，语法分虚高 | 已定纪律：以转写原文为准 + 对"异常干净"的段落保持怀疑 |
| 口音导致整词崩塌 | `Eiffel Tower` → `the I feel tower` | 双引擎交叉验证；单引擎异常一律降为低置信 |
| 词级置信度被误用 | 有人会想把它折算成分数 | 明确禁止：**置信度只用于给听点排序**，与发音好坏没有验证过的映射 |
| 标点不可靠 | 同一段录音，一个引擎给 5 题带问号，本机只给 2 题 | 题目对齐**不依赖标点** |
| 念题差异假阳性 | "多读 X"其实是上一题答案的尾部 | 已改为只在匹配窗口内部算差异；告警不得单独作为结论 |
| 单题词数有 ±2–4 词误差 | 交界处怎么切直接影响数字 | 验收标准是"逐题答词数相对人工基线偏差 ≤5%"，单题词数当近似值 |
| 两个讯飞引擎差 18 分 | 同一段录音：suntone 79.6 / 流式版 61.3，映射差两档 | 已定：suntone 主评分、流式版只做质检，**绝不可混用出分** |
| A2 互动交际在纯转写里测不到 | 真盲第四轮唯一掉出 ±1 档的点就是这个（官方 5 → 3.5） | 已记为工具边界：只拿纯转写时宜标"待补" |
| 跨引擎数字不可比 | 同一录音两引擎答题词数差 8%、停顿数差 67% | 已定铁律：同一学生跨批次对比**必须同引擎** |
| 云端转写引擎未验证 | 代码已实现，未用真实 key 跑过 | 仍在"未验证"清单里 |
| 图片类题型只能弱提示 | 静态文本查不出"有没有图" | 校验器只能给 warning，靠人守 |

## 五、待改进项（按优先级）

### P0 · 卡住 1.0 的两件事

1. **低档（0–2）判档真值。** 现在四轮都只覆盖 3–5 档。需要老师给 2–3 个学生的真实判档当真值（**注意**：库里那几份旧分数是用旧尺子给的，进语料前要按现行量表重判一次——这与"已发出的家长反馈不重评"是两件事）。
2. **发音档位真值。** 这是唯一零外部真值的维度。现有映射阈值（≥90→5、80–89→4、70–79→3、60–69→2、<60→1）是自定的**教学映射，不是官方换算表**；需要老师听一段音频给一个自己的档位，才能检验这个阈值。**改阈值必须同步改三处**（映射代码、量表 5.3、验证文档 §8.4 的锚点表），否则一致性断言会红。

### P1 · 方法学与规则

3. **n = 1 的问题**：同一批语料跑 2–3 个判官实例看分布，才能把"rubric 改动起效"和"这一轮判官手松"分开。
4. **换语料**：现在四轮都是同 6 条 case。
5. **残余偏严 −0.47**：方向没消掉，需要继续找是哪些判据把中段压低了。
6. **转写偏差的测量**：语法维度知道"有偏差"，不知道方向和幅度——需要拿原始音频人工核对一批，量出来。
7. **A2 互动交际的证据边界**：纯转写场景下应默认标"待补"，而不是给一个推断出来的档。

### P2 · 工程与体验

8. **云端转写引擎的真实跑通**（含单文件体积上限、网络可达性）。
9. **图片类题型半自动化**：现在只能靠人识别信号词并索要图片。
10. **跨引擎数字归一**：目前只能靠"固定用同一个引擎"规避。

## 六、路线图与 1.0 的门槛

**门槛的判据是"覆盖区间"，不是"跑过一次"**：

> `1.0.0` = 完成 **≥5 个真实 case** 的校准，**且低档（0–2）也有真值**，并且**完全一致率与系统性偏差可以公布**（主指标不是 ±1 档一致率）。

**现在差什么**：case 数与低档覆盖率的组合仍不达标 —— 6 条 case 全部落在 3–5 档，**低档一个点都没有**；发音维度零覆盖；n = 1。所以**版本停在 0.9.0**，分项分只能当教学参考，不能当官方判定。

到 1.0 的路径只有一条：**真实批改案例**（见下一节）。

## 七、怎么贡献（把真实批改变成校准燃料）

这个项目最需要的东西是**老师怎么判档**。路径如下（细节在 `CONTRIBUTING.md` 与 `docs/calibration.md`）：

1. **攒 case**：一个学生一个目录，放原音频（**只留本机**）、本机转写 JSON、底稿、AI 分项预估、老师真实给分。学生只用代号（甲 / 乙 / 丙），不要真实姓名。
2. **守判档顺序**：先只拿语料判档写 `ai-分项.json`，**判完再写** `teacher.json`；保留文件 mtime 作留证。
3. **`teacher.json` 里最值钱的不是分，是 `notes` 和 `would_correct`** —— 老师每个维度一句"为什么给这个档"，以及"我真的会改的句子"。**只看分差不知道改哪儿，看到理由才知道该收紧哪条锚点。**
4. **跑校准器**看一遍整体：`scripts/kpf_calibrate.py --root <cases 目录>`。
5. **先归纳一个偏差，不要逐案打补丁**：5 个 case 里 4 个都被同一条判据压低，那就是判据的问题；只有一个 case 偏，那是这个 case 的问题。
6. **改规则后必跑 `make check`**（四道闸门），并把结果与原数字一起记进 `docs/calibration.md` —— **标明这一轮是盲判还是非盲、样本落在哪些档**。
7. **真实 case 想公开**，先按 `docs/calibration.md` 第四节匿名化：换代号、抹姓名与个人路径、转写成匿名静态文本，再进 `tests/fixtures/` 当回归夹具。

**写规则时最容易踩的两个坑**（各踩过四轮，`CONTRIBUTING.md` 有专门说明）：
- **门槛必须逐级别写**：A2 / B1 / B2 是三张不同的量表，"回答超出短句就是 3 档"这种一句话概括必然对某一级是错的。
- **机械断言锁不住说明文字**：一致性脚本只锁表格结构，说明文字里的级别混用只能靠人逐项回表核对。

## 八、诚实总结

- **能信的部分**：转写、切分、指标、格式合规、证据可溯、防编造 —— 这些有实测证据，也有闸门盯着。
- **要小心的部分**：判档（完全一致 18.8%、偏严半档，只擅长"相邻档"；**而且它真正负责、也真正有证据的语法与词汇 + 话语组织是完全一致 0/10**）、语法维度（转写偏差方向未知）、低档（没验证过）、发音（零外部真值）。
- **不能信的用法**：拿它定档、拿它预测考试分数、拿它在没有对手方的录音上评互动交际。
