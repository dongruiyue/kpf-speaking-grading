# 02 · 机制：从一段录音到三份成品

> 上一篇：`01-problem-and-principles.md`（原理）· 下一篇：`03-usage.md`（使用方法）
> 本篇讲"它怎么运转"；每条命令的完整参数见 `README.md`，规则措辞见 `references/`。

## 一、总览

```
一段录音 / 视频
   │
   ├─① 转写（本机 whisper 或云端）─────────────→ <文件名>--<引擎>.json
   │
   ├─② 切问答 + 算硬指标 ─────────────────────→ 批改底稿.md
   │        （每题词数 / 答段秒数 / 语速 / 停顿 / 念题差异 / 低置信度词点位）
   │
   ├─③ 发音评测（讯飞 → 本机疑点 → 老师手填）──→ 发音报告.md
   │
   ├─④ 生成三份成品 ─────────────────────────→ 作业记录 / 家长版 / 学生版
   │
   ├─⑤ 归档 ──────────────────────────────────→ work/<日期>-<学生>/
   │
   └─⑥ 交付前校验（闸门：有 error 不许交付）
```

三个关键分工：

- **机器做的**：转写、切问答、算指标、调发音引擎、套模板、查合规。
- **人做的（且只做人做的）**：判断作业形态、索要图片类题型的图、决定互动交际、改措辞，以及最后跑一遍闸门并处理它报出来的 error。
- **机器不许做的**：给发音分、给互动交际分、给单篇总分、编学生原句。

## 二、六步逐条：输入 / 输出 / 失败模式

| 步 | 命令 | 输入 → 输出 | 已知失败模式与对策 |
|---|---|---|---|
| **0 环境** | `bash scripts/setup.sh`；`make doctor` | — → `.venv/` + 本机模型 | 用小模型（`tiny`）会导致题目对齐度 0%，实测不可用，**必须 `large-v3-turbo` 或更大**；系统代理指向未启动的代理程序会阻断模型下载，脚本默认绕过；讯飞没在控制台**开通**服务时接口直接报错 |
| **1 转写** | `scripts/kpf_asr.py transcribe` | 音频 / 视频 → 统一 schema 的 JSON | `.mov / .mp4` 自动取音轨，**不需要 ffmpeg**；ASR 会把不合法句子"顺"平、口音会让整词崩塌 → 用第二引擎交叉验证；产物名固定 `<文件名>--<引擎>.json`，引擎名可溯源 |
| **2 分析** | `scripts/kpf_analyze.py` | JSON + 题库 txt → 批改底稿 | 念题差异有**假阳性**（上一题答案尾部被并进题干窗口）→ 只在匹配窗口内部算差异；单题词数有 ±2–4 词边界误差 → **不得单独作为结论** |
| **2′ 互动证据**（可选；只在**有对手方**的录音上做） | `scripts/kpf_interact.py` | JSON + 原音视频 → `<转写名>-互动证据.md` | 两位考生音高重合、或没给 `--media` → **拒绝区分说话人**，只出沉默/交接间隙并写明"提示次数未测"；考官音高跨带会顶高"提示次数"（是上限） |
| **3 发音** | `scripts/kpf_pronounce.py` | JSON + 题库 → 发音报告 | 朗读型接口**必须有参考文本**，所以 `--questions` 是硬要求；缺参数或凭证会明确降级并打印原因，**不静默给 0 分**；乱读 / 音质差会被拒识（`is_rejected`），该句剔除出平均并显式标注 |
| **4 成品** | `scripts/kpf_report.py`（跑三次） | 底稿 → 三份 md | `--form`（`自问自答` / `独白` / `对话`）决定互动交际措辞；**含对手方的对话录音绝不能被写成"自问自答"**；不给形态就留占位符，由人填 |
| **5 归档** | `--out` 指定路径 | — → `work/<日期>-<学生>/` | 落库是**可选**的，且是**两阶段**：AI 起草先进"待确认"目录，老师确认后才进正式目录 |
| **6 校验** | `scripts/kpf_validate.py` | 报告 → 退出码 | 见下一节 |

## 三、四道闸门分别在防什么

| 闸门 | 命令 | 防的是什么 | 判据 |
|---|---|---|---|
| **报告合规** | `scripts/kpf_validate.py` | 单份成品踩红线：禁用词、带量化的技术指标、引擎原始分、单篇「总分」、缺免责句、markdown 表格、A2 多写「话语组织」、有"独自录音"却给互动交际打分、**核心维度（语法与词汇/话语组织）写「待补」** | 有 error → **退出码 1**，逐条打行号；warning 只打印 |
| **防编造** | 同上，加 `--transcript` | 报告里"他说的 X 应为 Y"和逐句修改表的原句**根本不是学生说的** | 归一化后在转写词序列里模糊查找：**< 0.85 → error**、0.85–0.92 → warning、≥ 0.92 通过。**家长版/学生版必须给转写稿**：不给就是 error（不能因为"忘了加参数"就静默放行）；确实没有转写稿时用 `--no-transcript-check` 显式承认，这个承认会打进 stdout 摘要 |
| **规则漂移** | `scripts/check_consistency.py` | 代码与文档打架：阈值、满分、A2 维度数、防编造边界、家长版技术指标分级、维度中英对照、引用路径、节号连续性、量表结构 | **14 项断言**（10 组），任一不成立 → 退出码 1 并打印两边取值 |
| **回归** | `tests/run_fixtures.py` | 校验器本身被改坏 | **34 个匿名夹具** + `expected.json`：退出码与 error/warning 计数必须逐项对齐 |
| **发布** | `scripts/check_publishable.py` | 学生姓名 / 班级 / 个人绝对路径 / 本机用户名 / 凭证 / 音视频名被提交进公开仓库 | 全仓文本扫描，命中即退出码 1 |

`make check` 把其中四道串起来（语法编译 + 规则一致性 + 夹具回归 + 发布闸门），**全程离线、不用任何 API key、秒级跑完**，所以 CI 在 push 与 PR 上都跑它（`ubuntu-latest`，只装标准库）。

> 为什么不把"校验"做成一次人工确认：因为人工确认会漏，而退出码不会。这条在项目里是被实证过的——自动生成的成品第一版就把技术指标写进了家长版。

## 四、规则效力体系（怎么保证几份文档不打架）

| 机制 | 做法 |
|---|---|
| 执行顺序 | 每个 `references/` 文件**按节号递增**执行 |
| 冲突裁定 | 跨文件冲突时，以 `references/02-rubric.md` 的官方分制与「单篇 / 完整模拟」口径为**最终裁定** |
| 单一职责 | `SKILL.md` 只做流程导航，不复述规则 |
| 唯一清单 | 全 skill 只保留一份自检清单 `references/checklist.md` |
| 数值唯一落点 | 阈值 / 满分 / 维度数 / 防编造边界只写在 `references/06-verification.md` §8.4，一致性脚本从那张表反解数值去比对代码 |
| 修 bug 的方式 | **物理替换作废内容**，禁止"追加新章节 + 声明效力更高"；一致性脚本第 [5] 组专门抓这类残留 |

## 五、降级链：拿不到就明说，不静默给分

发音维度按顺序尝试：**讯飞 ISE（xfyun）→ 本机疑点（local）→ 老师手填（manual）**。任一成功即用；全部不可用时**在 stderr 打印每一步的降级原因**，并且不产出分数。

这条规矩是修出来的。旧版有过两个真实缺陷：拿不到分时把空值渲染成 `0.0 → 1/5` 且退出码 0（等于静默给了个错分）；成功句数为 0 时也照常出报告。现在：`ok=True` 但 `overall is None` 改判失败；空值输出"未取得"；**成功句数为 0 时非零退出**。

同一类的还有一处：0–5 的教学映射**只有一份实现**（`scripts/kpf_xfyun.py` 的 `to_band()`：≥90→5、80–89→4、70–79→3、60–69→2、<60→1），其它脚本 import 它，不再各写一份。这是**教学映射，不是官方换算表**。

## 六、产物结构与命名

```
work/<日期>-<学生>/
├── <文件名>--local.json        # 转写（统一 schema，含词级置信度）
├── <文件名>--groq.json         # 可选：第二引擎，用于交叉验证
├── 交叉验证.md                 # 可选：两引擎比对
├── <学生>-底稿.md              # 硬指标 + 逐题问答原文 + 念题差异 + 发音疑点
├── <学生>-发音.md              # 发音评测报告
├── <学生>-作业记录.md          # 内部档案：原始分 + 映射分 + 逐项详评
├── <学生>-家长.md              # 纯文字，可直接粘微信
└── <学生>-学生.md              # 逐句修改表 + 升级表达
```

另有两条全局产出：**错误卡**（个人）与**班级共性卡**——同一个错误出现在 ≥2 名学生身上，就升级成班级共性卡，不要各自摊在学生目录里。改正版作业用同一套脚本重跑、逐条核验"上次反馈的每一条是否落地"，这比新批一份价值更高。

## 七、隐私与网络：默认不出本机

| 路径 | 音频去哪 | 代价 |
|---|---|---|
| 本机转写（默认） | **不出本机** | 免费无限，约 3 倍实时 |
| 云端转写（可选） | 上传到对应服务 | 秒级出稿，但需能访问该服务 |
| 讯飞发音评测 | 上传**念题片段** | 免费额度；一页 5 题 = 5 次 |

默认路径（本机 whisper）就是为这条铁律设计的：学生姓名、录音、学情只留本机。公开仓库里的测试夹具全部是匿名静态文本，不含任何真实学生数据。

## 八、一句话总结机制

> **每一步都有明确的输入、产物和失败模式；失败时降级并出声，而不是静默给一个假结果；最后用退出码把关。**
