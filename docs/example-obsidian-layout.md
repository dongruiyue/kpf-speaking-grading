# 示例：作者的个人 Obsidian 落库布局

> **作者的个人工作流示例，仅供参考，非必需。** 本 skill 不绑定任何笔记库；换成你自己的目录结构、Logseq、或纯文件夹都行。落库的配置方式见 `../references/05-output-and-vault.md` 第二节。

作者本人用 Obsidian 做教学中枢，库根目录即本机的个人笔记库（此处以 `<vault-root>/` 代指，不在仓库里写真实路径）。库内规范来自该库自己的 `AGENTS.md`；下面是把它落地到本流程的样例。

## 三条库内约定（作者的）

1. **标准课程内容与学生个性化记录分开**。
2. **一份笔记只存自己的事实**，靠链接关联，不复制。
3. **排课 / 上课时间只存在一处**，别处用链接。

## 目录树

```text
<vault-root>/
  90-待整理资料/02-待你确认/             # AI 起草的落库件先放这里，等教师确认
    <日期>-<姓名>-<作业名>-作业记录.md
    <日期>-<姓名>-<作业名>-错误卡.md

  30-学生/                               # 教师确认后，正式目录
    @<姓名>/
      00-学习主页.md                     # 该学生的唯一日常入口
      01-课堂记录/<日期>-<课程>-<主题>.md
      02-作业与提交/<日期>-<班级>-<作业名>.md
      03-错误卡/<能力点或语法点>.md       # 个人错误卡
    姓名&姓名（1对2）/                    # 固定 1 对 2 另建共同档案
      00-课程档案.md

  50-错误与复习/                          # 班级共性错误
    <能力点>（<具体问题>）.md

  90-待整理资料/03-原始资料归档/口语作业转写/
    <日期>-<姓名>-<班级>-<作业名>/
      <日期>-<姓名>-<班级>-<作业名>.md    # 可读转写原文（Obsidian 可搜）
      raw/                               # 引擎原始 JSON + manifest

  90-待整理资料/04-入库日志/入库日志.md    # 每次落库追加一行
```

命名要点：日期用 `YYYY-MM-DD`；文件名里不出现 `&`、`/`、`:`；一页多题写清楚页号（如 `P102`）。

## 产物 → 目标目录 映射（作者的做法）

| 产物 | 目标目录 |
|---|---|
| 作业记录 | `30-学生/@<姓名>/02-作业与提交/` |
| 个人错误卡 | `30-学生/@<姓名>/03-错误卡/` |
| 班级共性卡 | `50-错误与复习/` |
| 转写归档（可读 md + 原始 json） | `90-待整理资料/03-原始资料归档/口语作业转写/<日期>-<姓名>-<班级>-<作业名>/` |
| 入库日志 | `90-待整理资料/04-入库日志/入库日志.md` |

## frontmatter 字段（作者的做法）

**作业记录（`02-作业与提交/`）**

```yaml
type: 作业
学生: <姓名>
班级: <如 FCE-A>
作业: <班级名 + 题型 + 页号>
布置日期: <YYYY-MM-DD 或 待补>
截止日期: <YYYY-MM-DD>
提交日期: <YYYY-MM-DD>
状态: 草稿 | 待提交 | 待批改 | 已完成
能力点: [<2–4 项>]
来源课堂:                       # 可选
```

**个人错误卡（`03-错误卡/`）**

```yaml
type: 错误卡
学生: <姓名>
班级: <班级>
能力点: <口语表达准确度 等>
语法点: <具体语法点；非语法问题写"无（话语组织问题）">
题型: <FCE Speaking Part 1 等>
状态: 待复习 | 复习中 | 已掌握
首次出现: <YYYY-MM-DD>
最近复习: <YYYY-MM-DD>
来源: "[[<作业记录路径>]]"
```

**班级共性卡（`50-错误与复习/`）**

```yaml
type: 错误卡
学生: <班级>（班级共性）        # 便于工作台 Dataview 汇总
涉及学生: <姓名、姓名、姓名>     # 累积，每发现一例就加
班级: <班级>
状态: 待复习 | 复习中 | 已掌握
首次出现: <YYYY-MM-DD>
最近复习: <YYYY-MM-DD>
```

## 状态流转（作者的）

- 作业：`草稿 → 待提交 → 待批改 → 已完成`（`草稿` 只用于"先存档后补分"，交付前必须转正式状态）
- 错误卡：`待复习 → 复习中 → 已掌握`
