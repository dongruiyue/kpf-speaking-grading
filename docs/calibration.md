# 校准：让分数对得上真人老师

> 这份文档讲**持续优化的路径**：每收到一批真实批改，怎么把它变成"规则改哪里"的依据。
> 相关文件：`templates/teacher-marks.json`（老师真实给分）、`templates/ai-marks.json`（AI 四项预估）、`scripts/kpf_calibrate.py`（算指标）、`scripts/kpf_anonymize.py`（脱敏成夹具）。

## 为什么需要这一步

本 skill 的分项分**已做过真人校准，并已按盲判复测过一轮**（2026-09-29 首判、2026-09-30 两轮盲判，数字与边界见下文的「两轮盲判结果」小节），但**覆盖区间很窄**：只验证了 3–5 档，低档（0–2）与发音维度都还没有外部真值。所以口径不变——**在覆盖到低档之前，分项分只能当教学参考，不能当官方判定**（**1.0.0 的门槛就是完成 ≥5 个真实 case 的校准，且完全一致率与系统性偏差可以公布**——主指标不是 `±1 档` 一致率，见下文的边界 5）。

校准的流程是一个闭环，不是一次性动作：

```
攒真实 case  →  跑 kpf_calibrate.py  →  读分歧清单  →  归纳一个系统性偏差
     ↑                                                      ↓
     └── 匿名夹具 ← make check 全绿 ← 改锚点口径 + 同步 §8.4 锚点表 ┘
```

**关键纪律：先归纳一个系统性偏差，不要逐案打补丁。** 看到 3 个 case 都"AI 比老师高 1 档"才有信息量；只看到一个 case 偏了、就专门为它加一条规则，等于把噪声写进规则里。

## 两轮盲判结果（2026-09-30 复测）· 基线是盲判，非盲数字只作对照

外部真值**不是老师口头印象，也不是本校学生的录音**，而是**剑桥官方发布的公开样题视频 + 配套官方给分文件**——公开视频，考官其实给过分。6 个 case：FCE(B2) 官方样题视频的两位考生、KET(A2) 两位考生、PET(B1) 两位考生。发音点一律是 AI 缺值、不进统计，**进入统计 16 个可比维度点**。

同一批语料做了**三轮判档**，差别只在判官事先知不知道官方分、以及用哪一版 rubric：

| 轮次 | 判法 | 完全一致 | ±1 档 | 整体平均带符号差 |
|---|---|---|---|---|
| **非盲对照**（作废，只作锚定对照） | 判官**已知**官方分；旧 rubric——即此前发布的那一次 | 14/16 = 87.5% | 16/16 = 100% | −0.06 档 |
| **盲判一轮**（旧基线） | 判官只看语料 + `references/02-rubric.md`，在隔离目录里判，语料里的考生姓名已替换成占位符，全程未看过任何官方分；**旧 rubric** | **2/16 = 12.5%** | **14/16 = 87.5%** | **−0.88 档（偏低）** |
| **盲判二轮**（现行基线） | 同样盲判（隔离目录、姓名替换、全程没看过官方分）；**现行 rubric**——即加了「5 档不是"完美"」那条锚点、并改了 A2 发音 / 单成分封顶 / "需要提示" 之后 | **6/16 = 37.5%** | **15/16 = 93.8%** | **−0.34 档（偏低）** |

### 盲判一轮的逐维度数字（旧基线）

| 维度 | 分母 | 完全一致 | ±1 档 | 平均带符号差 |
|---|---|---|---|---|
| 语法与词汇 | 6 | **1/6 = 16.7%** | 6/6 = 100% | **−0.83** |
| 话语组织 | 4 | **0/4 = 0%** | 4/4 = 100% | **−0.75** |
| 互动交际 | 6 | **1/6 = 16.7%** | **4/6 = 66.7%** | **−1.00** |
| **合计** | **16** | **2/16 = 12.5%** | **14/16 = 87.5%** | **−0.88** |

盲判一轮 `|差| ≥ 1 档` 共 **11 条**（其中 9 条正好差 1.0）。**16 个点全部偏低或持平、0 点偏高；偏差以顶端为主、但中段也有**：官方 **5 档**的 11 个点贡献了 **10.5/14 = 75%** 的绝对误差，模式是"该给 5 时不给 5"（三位被考官全给 5 的考生，盲判在语法与词汇 / 话语组织 / 互动交际上给成 4 / 4.5；KET 两位的互动交际被压到 3 与 3.5，差 −2 与 −1.5）；官方 **3–4 档**的 5 个点里**有 4 个也不一致**，贡献 **3.5/14 = 25%**。所以"中段无偏差"这个读法是错的——逐维度 `±1 档` 一致率 100%（语法与词汇 6/6、话语组织 4/4）只说明"没有差过一档"，**不等于没有偏差**（这两项的完全一致率只有 1/6 = 16.7% 与 0/4 = 0%）。**后续校准不能只盯 5 档。**

逐点对照（官方 → 盲判一轮）：

```text
 FCE 考生一   语法词汇 5→4(-1)   话语组织 5→4(-1)    互动交际 5→5(0)
 FCE 考生二   语法词汇 3→3(0)    话语组织 3→2.5(-0.5) 互动交际 4→3(-1)
 KET 考生一   语法词汇 4→3(-1)                       互动交际 5→3(-2)
 KET 考生二   语法词汇 4→3(-1)                       互动交际 5→3.5(-1.5)
 PET 考生一   语法词汇 5→4(-1)   话语组织 5→4.5(-0.5) 互动交际 5→4(-1)
 PET 考生二   语法词汇 5→4(-1)   话语组织 5→4(-1)     互动交际 5→4.5(-0.5)
```

### 盲判二轮的逐维度数字（现行基线）

| 维度 | 分母 | 完全一致 | ±1 档 | 平均带符号差 |
|---|---|---|---|---|
| 语法与词汇 | 6 | **1/6 = 16.7%** | **5/6 = 83.3%** | **−0.42** |
| 话语组织 | 4 | **2/4 = 50.0%** | 4/4 = 100% | **−0.25** |
| 互动交际 | 6 | **3/6 = 50.0%** | 6/6 = 100% | **−0.33** |
| **合计** | **16** | **6/16 = 37.5%** | **15/16 = 93.8%** | **−0.34** |

换 rubric 之后的净变化：**完全一致 2/16 = 12.5%（一轮）→ 6/16 = 37.5%（二轮）**、**±1 档 14/16 = 87.5%（一轮）→ 15/16 = 93.8%（二轮）**、**整体偏差 −0.88（一轮）→ −0.34（二轮）**；`|差| ≥ 1 档` 从一轮的 **11 条**降到二轮的 **2 条**（其中 1 条正好差 1.0）。

二轮的**逐点档位差分布**（这是"能不能相加"的关键）：

| 档位差 | 点数 |
|---|---|
| 0.0 | 6 |
| ±0.5 | 8 |
| ±1.0 | 1 |
| −1.5 | 1（唯一超出 ±1 档的点） |

**这张表不能按"列相加"读**：`±1 档` 是**包含关系**——0 与 ±0.5 都算在它里面（6 + 8 + 1 = 15，正是 15/16 = 93.8%），所以它**不能与"完全一致"相加**；校准器的表头写的也是「±1 档（含完全一致）」。

逐点对照（官方 → 盲判二轮）：

```text
 FCE 考生一   语法词汇 5→4.5(-0.5) 话语组织 5→5(0)      互动交际 5→5(0)
 FCE 考生二   语法词汇 3→1.5(-1.5) 话语组织 3→2.5(-0.5) 互动交际 4→3.5(-0.5)
 KET 考生一   语法词汇 4→4.5(+0.5)                      互动交际 5→4(-1)
 KET 考生二   语法词汇 4→3.5(-0.5)                      互动交际 5→4.5(-0.5)
 PET 考生一   语法词汇 5→5(0)      话语组织 5→5(0)      互动交际 5→5(0)
 PET 考生二   语法词汇 5→4.5(-0.5) 话语组织 5→4.5(-0.5) 互动交际 5→5(0)
```

### 二轮最值钱的一条发现：顶端抬上来了，中段还是偏严

**锚点确实把顶端抬上来了**：PET 两位考生的六个点在一轮里全是 4 / 4.5 档，二轮升到 4.5–5 档、**没有再出现 4 档**；其中一位的三项（语法与词汇 / 话语组织 / 互动交际）**全部命中 5 档**，与考官完全一致。

**但二轮唯一掉出 ±1 档的点，恰恰是中档考生的语法与词汇**——官方 3、盲判给 1.5（**−1.5 档**）。判官的理由是**严格按表走的**：B2 语法词汇的 **1 档逐字等于** A2 的 5 档（"对简单语法形式有良好的掌控 + 日常情境一系列恰当词汇"，见 `references/02-rubric.md` 用法第 2 条），而这位考生**只满足后半个条件**（词汇够、形式控制不足），按偶数档口径落 1.5。**结论：「半个条件满足」这类中段判法仍偏严——下一个杠杆在中段，不在顶端。**

### 非盲对照证明了什么

**同一位判官、同一批语料，只要事先看过官方分，完全一致率就从 12.5%（盲判一轮）跳到 87.5%（非盲）。** 这组数字只能当"锚定效应有多大"的对照、**不得再作为结论**。因此：

- 此前发布的 **8/10 = 80%、±1 档 10/10**（4 case 版本）与 **14/16 = 87.5%、±1 档 16/16**（6 case 版本）**都是非盲数字，都被锚定高估**；
- **对外基线是盲判**：最新一组是上面的**盲判二轮**（6/16 = 37.5% / 15/16 = 93.8% / −0.34）；盲判一轮（2/16 = 12.5% / 14/16 = 87.5% / −0.88）保留作复测前的对照。

### 读这些数字时必须同时看的五个边界

1. **样本严重偏上 → 这两轮都只验证了 3–5 档。** 16 个官方分点**全部落在 3–5 档**、**0 个**落在 0/1/2 档。作者实际带的学生多在 1–3 档，**低档（0–2）仍然没有任何外部验证**。两轮说的都是"3–5 档这一带对得上"，不是"分项分可信"。
2. **语法与词汇另有已识别的转写偏差，方向与幅度都未测量** —— 本机 whisper 会自动把学习者的错误改对（实测：官方评语引用的原句含三处错误，转写把它们改成了正确形式），所以转写比真实口语更正确。它对一致率的影响**可能美化、也可能加大偏差，方向与幅度都没有测量**，所以语法维度这一项的数字要按"已知有偏差、大小未知"来读。
3. **发音维度仍是 0 校准。** 官方样题是**对话考试**，而讯飞 ISE 是**朗读型**接口、必须有参考文本——本工具无法在对话录音上评发音。发音点全部是"AI 缺值"。
4. **锚定效应已实测（2026-09-30）。** 同一批语料，判官**知道** vs **不知道**官方分，完全一致率 **87.5%（非盲）vs 12.5%（盲判一轮）**；二轮仍是盲判，**37.5%**——三个数字一起看：**知道分的那一组（87.5%）远高于两轮盲判（12.5% / 37.5%）**。结论是方法上的：**判档必须在看官方分之前完成**，否则数字不成立——顺序与留证办法见「一、语料怎么攒」里的「判档顺序」。
5. **"绿灯门槛太松"（2026-09-30 新增）。** 校准器的主指标是 `±1 档` 一致率、阈值 80%；盲判**一轮**整体偏低 0.88 档、`|差| ≥ 1 档` 有 11 条，**却仍然算绿灯**（87.5% ≥ 80%）；盲判**二轮**同样是绿灯（93.8% ≥ 80%），而**完全一致率只有 37.5%**。所以 **绿灯 ≠ 判分可用**：**完全一致率与系统性偏差才是主指标**，`±1 档` 只是"相邻档分歧在教学上是否可以接受"的旁证。**阈值本身没有改，改的是对它的读法。**

### 这两轮数字的三条限制（与上面五个边界一起读）

1. **每一轮只有一个判官实例，而且两轮是两个不同的实例。** 所以 **12.5% → 37.5% 这一跳里，"锚点起效"与"这位判官手松一些"分不开**——n = 1，只能看方向，**不能当精度指标**。要立住得同一批语料跑 2–3 个判官看分布。
2. **语料没变**：还是同 6 条 case 反复用，二轮不是新样本、也不是新语料。
3. **低档（0–2 档）与发音维度仍然零覆盖**：16 个可比点**全部落在 3–5 档**，发音 6 个点**全是 AI 缺值**（就是上面边界 1 与边界 3 说的两件事，在这里重述，是因为它们决定了这两轮数字能覆盖多远）。

**结论**：门槛判据是覆盖区间，不是"跑过一次"。低档（0–2）与发音维度的外部真值仍然为零；两轮盲判的**完全一致率从 12.5% 升到 37.5%、整体偏差从 −0.88 收到 −0.34**，方向是好的，但 **n = 1、语料未换，仍只是方向性证据**，离 `1.0.0` 的门槛（≥5 个真实 case 且低档也有真值）还差得远 —— **1.0.0 的门槛仍未达**。带名字的完整报告、音视频与转写都留在仓库外的私有校准目录，不进仓库。

## 一、语料怎么攒

放在**仓库外**，一个 case 一个目录（目录名与 `case_id` 都不要写真实姓名——校准报告可能被贴进 issue 或聊天记录）：

```text
~/Documents/口语批改工作区/_calibration/<日期>-<学生代号>/      如 2026-10-08-甲
  audio/                     原音视频（只留本机，永不提交）
  <文件名>--local.json       本机转写（脚本要读它取问答切分）
  ai-底稿.md                 kpf_analyze.py 出的底稿（可读）
  ai-分项.json               AI 四项预估，格式见 templates/ai-marks.json
  teacher.json               老师的真实给分，格式见 templates/teacher-marks.json
```

- 学生只用代号（甲 / 乙 / 丙）。
- `teacher.json` 是**必需**的；`ai-分项.json` 可选——没有它时工具会退而从 `作业记录.md` 的「分项评分 / 四项预估」表格里解析档位，两条路都走不通就报错（不会把这个 case 悄悄跳过）。
- **`teacher.json` 里最值钱的是 `notes`**（每个维度一句人话，老师为什么给这个档）和 `would_correct`（老师真的会改的句子）。只看分差不知道改哪儿，看到理由才知道该收紧哪条锚点。
- 独白 / 自问自答的 `互动交际` 写 `null`：本来就没有对手方，不要为了凑数填一个分。老师给 `null` 的维度不进统计，但会单独列出来。

### 判档顺序（纪律，不是建议）

**判档必须在看官方分 / 老师分之前完成。** 这不是洁癖：实测同一批语料，**事先知道官方分时完全一致率 87.5%，不知道时只有 12.5%（盲判一轮）/ 37.5%（盲判二轮）**（数字见上面「两轮盲判结果」的边界 4）。照这个顺序做：

1. **先只拿语料判档**——按 `references/02-rubric.md` 独立判，写出 `ai-底稿.md` 与 `ai-分项.json`；
2. **判完之后**才去写 `teacher.json`（老师 / 官方的真实给分）；
3. 判档时用**隔离目录**：把语料复制到仓库与工作区之外的一个空目录里跑，**把考生姓名替换成占位符**，全程不看任何官方分；
4. **保留文件 mtime**：`ai-分项.json` 的写入时间早于 `teacher.json`，这就是"这次判档是盲的"的留证。

以后每条新 case 都照这个顺序做。反过来的话（先看了 `teacher.json` 再补 `ai-分项.json`），这条 case 的数字只能标成"**非盲对照**"，不许进基线统计。

## 二、怎么算指标

```bash
# 指定若干 case 目录
python3 scripts/kpf_calibrate.py <case目录> <case目录> ...

# 或者扫一个工作区的一级子目录（含 teacher.json 的才算 case）
python3 scripts/kpf_calibrate.py --root ~/Documents/口语批改工作区/_calibration

# 换阈值 / 只看 AI 侧明确标了 AI 的行 / 顺手存一份报告
python3 scripts/kpf_calibrate.py --root <工作区> --min-agreement 0.8 --ai-party ai-only --out <报告.md>
```

工具只读输入、离线、不联网、不读凭证、不碰音频与转写本体。报告里有五块：

| 块 | 看什么 |
|---|---|
| 一、逐维度一致率 | **主指标是 ±1 档一致率**（相邻档分歧在教学上可以接受）——它**包含完全一致**，所以两者不能相加；完全一致率是更严的次指标。另给平均带符号差与平均绝对差 |
| 二、系统性偏差 | AI 整体偏高还是偏低、**哪个维度最容易偏**、偏高/持平/偏低各几点 |
| 三、混淆矩阵 | 每个维度一张"AI 给了几档 × 老师给了几档"的矩阵，一眼看出往哪个方向堆 |
| 四、分歧清单 | AI 给什么 / 老师给什么 / 老师理由 / **AI 当时引的证据**——这是改规则时唯一的入口 |
| 五、不进统计的部分 | 老师给 `null`（无证据）与 AI 缺值的点，明说是"无证据"而不是零分 |

`--min-agreement` 默认 0.8：**±1 档一致率低于它就退出码 1**。进入统计的 case 少于 3 个时，工具只当"冒烟"、明确说数字不能用来判红。

## 三、怎么用报告（关键：先归纳一个偏差，不要逐案打补丁）

1. **读分歧清单**，先只看 `|差| ≥ 1 档` 的条目，跳过老师置信 `low`、也跳过双方都没写理由的条目。
2. **归纳出一个系统性偏差**——一句话说得出来才算数，例如"AI 在语法与词汇上普遍比老师高 1 档，因为它把'错误可见但不影响理解'都算到了 3 档"，或"AI 把口语里的重复和犹豫算进了话语组织，老师不算"。
3. **改判定口径**：动 `references/02-rubric.md` 的锚点或 `references/03-scoring-rules.md` 的证据等级。**改的是口径，不是某个学生的分。**
4. **同步 `references/06-verification.md` §8.4 锚点表**（改了阈值/数值就必须同步，否则 `check_consistency.py` 会报漂移）。
5. **为这个偏差补一个匿名夹具**（见下一节），让它成为回归用例——以后谁再改回去，`make check` 会红。
6. **`make check` 全绿**后再跑一次校准，确认一致率真的上升。
7. **在 `CHANGELOG.md` 记一行**，带上数字：`因 N 个真实样本，±1 档一致率 X% → Y%`。

一次只改一个偏差。同时改三处口径，下次报告变好也不知道是哪一处起的作用。

## 四、怎么把真实 case 变成可公开的夹具

```bash
python3 scripts/kpf_anonymize.py <真实case目录> --out <产物目录> --dry-run   # 先看会替换什么
python3 scripts/kpf_anonymize.py <真实case目录> --out <产物目录>
```

替换规则（都在帮助里有原文）：

| 原样 | 换成 |
|---|---|
| 真实姓名 | 学生甲 / 学生乙 / 学生丙（可用 `--map 姓名=代号` 指定） |
| 班号（`<级别字母><2–4 位数字>`） | `FCE-A` 这类形式 |
| 家目录绝对路径 | `<工作目录>`（保留后面的目录结构） |
| 音视频文件名 | `P<页号>-<代号>` + 原扩展名 |
| 转写 JSON 的 `meta.student` / `class` / `file` | 一并替换 |

**保留**：所有英文原句、分数、耗时、指标——夹具的价值就在错误类型与数据形态，改了就没用了。

写完它会**自动复扫一遍**产物目录（姓名 / 班号 / 绝对路径 / 产物 JSON 可解析），有残留就退出码 1 并指出位置。产物目录里不要放真音频：`--media` 默认 `skip`（只改引用名），要授权时才用 `copy`。

`--mapping-out <路径>` 可以把"原名 → 代号"对照表写到你自己的留档位置（**禁止写在 `--out` 里**，那等于把对照表一起公开了）。

一次实际运行（合成样例）长这样：

```text
$ python3 scripts/kpf_anonymize.py <真实case> --out <产物目录> --names 某姓名
已写出产物：<产物目录>/<case>/
文本 2 个（内容已替换）· 音视频 0 个（策略 skip）· 其他二进制 0 个（策略 skip）

自检通过：<产物目录> 下没有姓名 / 班号 / 绝对路径残留，产物 JSON 均可解析
```

注意两个**它做不到的事**，产物要自己复核：

- 姓名是自动识别 + 启发式兜底的。识别不到时会明确提示（`没识别到学生姓名…请用 --names 显式给出`），此时用 `--names` 显式给，别当它已经改好了。
- 它做的是文本替换，不重排句子：如果原句里本来就带着"学生"两个字（例如标题写成"学生某某 口语批改底稿"），替换后会留下 `学生学生甲` 这种叠字。这类残留不影响校验，但公开前值得手工顺一遍。

## 五、公开与私有的边界

| | 留在本机的 | 可以进公开仓库的 |
|---|---|---|
| 音频 / 视频 | ✅ 全部 | ❌ 一律不进（音视频后缀与 `*.local.json` 都在 `.gitignore` 里） |
| 真实姓名 / 班级 / 学校 | ✅ | ❌ |
| 转写全文 | ✅ | ⚠️ 只在匿名夹具里，且只保留必要的原句 |
| 分数与指标 | ✅ | ✅ 可以 |
| 规则与方法论 | — | ✅ 全部（`references/`、`docs/`、`SKILL.md`） |
| 一致率结论 | ✅ | ✅ 可以（这正是校准要产出的对外结论） |

一句话：**公开仓库只拿到"规则 + 匿名夹具 + 指标结论"这三样**，真实语料与音频永远不出本机。

## 六、第一批该怎么做（起步建议）

1. **先攒 3–5 个 case**，不求多：覆盖不同级别（尽量有 KET/PET/FCE 各一）、不同水平（一个明显好的、一个明显弱的、一两个中间），并且**要挑你已经给过分、还能说清为什么的**。凑不满 3 个以前，工具只会给"冒烟"结论。
2. `teacher.json` 一次填完，`notes` 一定要写——只填分不写理由，下次只能看到"偏了 1 档"，看不到"该改哪条锚点"。
3. 跑第一份报告：

   ```bash
   python3 scripts/kpf_calibrate.py --root ~/Documents/口语批改工作区/_calibration --out <报告.md>
   ```

4. **把这份报告的关键数字贴进 `references/06-verification.md` 的「真人校准」条目**，把它从 ⬜ 改成**部分完成**——而且要**把样本边界与数字写在同一句里**（case 数、**官方分点落在哪些档**、逐维度完全一致率与 ±1 档一致率、系统性偏差方向），并且**标明这一轮是盲判还是非盲**（顺序见「一、语料怎么攒」的「判档顺序」）。首轮就栽在这里：官方分点全落在 3–5 档，一致率很漂亮，但**低档与发音维度一个点都没验证到**——只写"已完成"就是报喜不报忧。**门槛的判据不是"跑过一次"，而是覆盖区间**：低档（0–2）也有真值 + case 数过关，两条都满足才算过。
5. 若一致率低于 0.8，按第三节的做法**只归纳一个最大的偏差**、改口径、补夹具、`make check`、再跑一次。
6. 别忘了把这一批真实 case 匿名化成公开夹具（第四节），让这批数据从此变成回归资产，而不是一次性的人工观察。
