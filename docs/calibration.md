# 校准：让分数对得上真人老师

> 这份文档讲**持续优化的路径**：每收到一批真实批改，怎么把它变成"规则改哪里"的依据。
> 相关文件：`templates/teacher-marks.json`（老师真实给分）、`templates/ai-marks.json`（AI 四项预估）、`scripts/kpf_calibrate.py`（算指标）、`scripts/kpf_anonymize.py`（脱敏成夹具）。

## 为什么需要这一步

本 skill 的分项分**已做过真人校准，并已按盲判复测过四轮**（2026-09-29 首判、2026-09-30 四轮盲判——**其中只有两轮是真盲，第 2、3 轮因为判官读的量表里写着答案而作废**；数字与边界见下文的「四轮盲判结果」小节），但**覆盖区间很窄**：只验证了 3–5 档，低档（0–2）与发音维度都还没有外部真值。所以口径不变——**在覆盖到低档之前，分项分只能当教学参考，不能当官方判定**（**1.0.0 的门槛就是完成 ≥5 个真实 case 的校准，且完全一致率与系统性偏差可以公布**——主指标不是 `±1 档` 一致率，见下文的边界 5）。

校准的流程是一个闭环，不是一次性动作：

```
攒真实 case  →  跑 kpf_calibrate.py  →  读分歧清单  →  归纳一个系统性偏差
     ↑                                                      ↓
     └── 匿名夹具 ← make check 全绿 ← 改锚点口径 + 同步 §8.4 锚点表 ┘
```

**关键纪律：先归纳一个系统性偏差，不要逐案打补丁。** 看到 3 个 case 都"AI 比老师高 1 档"才有信息量；只看到一个 case 偏了、就专门为它加一条规则，等于把噪声写进规则里。

## 五轮盲判结果（2026-09-30 复测）· 只有真盲轮进基线

外部真值**不是老师口头印象，也不是本校学生的录音**，而是**剑桥官方发布的公开样题视频 + 配套官方给分文件**——公开视频，考官其实给过分。6 个 case：FCE(B2) 官方样题视频的两位考生、KET(A2) 两位考生、PET(B1) 两位考生。发音点一律是 AI 缺值、不进统计，**进入统计 16 个可比维度点**。

同一批语料做了**五轮判档**，差别在**判官事先知不知道官方分**、**用哪一版 rubric**，以及**第五轮判官多拿到了互动证据**。**关键：第 2、3 轮并不真盲** —— 那两轮判官要读的量表副本里当时写着官方分与历轮结果（"三位被考官全给 5""11 个点是 5 档""中段轨迹 3 → 1.5 → 3.5"这类句子），**判官读到量表就读到了答案**，所以那两轮的数字**不计入基线、不作 rubric 效果的证据**（泄漏路径与修法见下面的「判档顺序」）：

| 轮次 | 是否真盲 | 完全一致 | ±1 档 | 平均带符号差 | 超出 ±1 档的点 |
|---|---|---|---|---|---|
| **盲判一**（旧 rubric） | **真盲** | 2/16 = 12.5% | 14/16 = 87.5% | −0.88 | 2 |
| 盲判二（+5 档锚点） | **污染（泄漏）** | 6/16 = 37.5% | 15/16 = 93.8% | −0.34 | 1 |
| 盲判三（+中段修正） | **污染（泄漏）** | 8/16 = 50.0% | 16/16 = 100.0% | −0.06 | 0 |
| 盲判四（现行 rubric · 净化版量表） | **真盲** | 3/16 = 18.8% | 15/16 = 93.8% | −0.47 | 1 |
| **盲判五（现行 rubric + 互动证据）** | **真盲** | **3/16 = 18.8%** | **15/16 = 93.8%** | **−0.53** | 1 |

五轮用的是同一套判档纪律：隔离目录、姓名替换成占位符、每轮换一个全新判官实例、把上一轮的产物挪出隔离目录。**对外基线是「盲判五」**（真盲、现行 rubric、判官另拿到互动证据）：完全一致 **3/16 = 18.8%**、±1 档 **15/16 = 93.8%**、平均带符号差 **−0.53**。（另有一组**非盲对照**，见下面的「非盲对照证明了什么」。）

**第五轮比第四轮多给了什么**：三场考试里 A2 Key 与 B1 Preliminary 两条视频能用新脚本 `kpf_interact.py` 可靠分出说话人，判官因此拿到了**考官对每位考生的提示次数、沉默统计、话轮交接间隙**；B2 那条两位考生音高重合、脚本**拒答**，只给了沉默类指标。**判官确实用了它** —— 它给这四位的互动交际档位时逐条引用了"高精度话术命中几条""连续发言段内 ≥1 s 停顿几次"。

### 第五轮开跑之前写下的预期 vs 实测（**预登记，不是事后解释**）

判官开跑之前先写了 `第五轮-预登记.md`，三条预期：**① C（上轮 −1.5）会明显上移；② D（上轮 −1.0）小幅上移或不动；③ FCE / PET 的互动交际点不应有系统性变化 —— 若整体移动 > 0.5 档，应当怀疑"这一轮判官整体手松/手紧"，而不是把它记成证据的功劳。**

| 预期 | 实测 | 判定 |
|---|---|---|
| ① C 互动交际上移 | −1.5 → **−1.0**（+0.5） | **部分成立**（动了，但只有半档，"明显"谈不上） |
| ② D 互动交际上移或不动 | −1.0 → **−1.5**（**下沉 0.5**） | **不成立** |
| ③ FCE / PET 互动交际不动 | FCE 两点 **0 → 0**（不动）；PET 两点 **−0.5 → −1.0**、**0 → −0.5**（各下沉 0.5） | **2/4 成立** |

**两个 A2 互动交际点平均仍是 −1.25（第四轮也是 −1.25）**：一个升半档、一个降半档，换了个方向，**没有变准**。也就是说 —— **那两个点的偏低不是"证据不足"造成的**：证据补齐了、判官也引用了，它照样不给 5 档。

### 比数字更重要的一条：换一个判官，16 个点里 10 个会动

第四轮与第五轮是**同一批语料、同一版 rubric、两个不同的全新判官实例**（差别只在互动证据）。逐点对比：

- **16 个点里 10 个移动了 0.5 档**（6 个偏低、4 个偏高），6 个不动。
- 移动的 10 个里**有 6 个与互动交际无关**（语法与词汇 / 话语组织）—— 这两个维度在第五轮**根本没拿到新证据**，照样动。
- 所以**轮间差异主要是判官噪声，不是我们想测的那个变量**。这条把「每轮只有一个判官实例」从"理论上的限制"变成了**实测到的量级**：**任何跨轮的"效果"归因（包括 12.5% → 18.8% 那一对）都必须先扣掉这个量级的噪声。**
- **噪声之上仍然站得住的结论只有一条**：判档**系统性偏严** —— 五轮真盲里整体偏差都在 −0.47 ~ −0.88 之间，**方向五轮一致**。

- **最后一列的口径是 `|差| > 1`**（掉出 ±1 档的点数），**不要与 `|差| ≥ 1 档` 混读**——后者的口径下盲判一轮是 **11 条**（其中 9 条正好差 1.0）。`±1 档` 本身**包含完全一致**（0 与 ±0.5 都算在里面），**不能与"完全一致"相加**。
- **最常被引用的对比是「真盲一 ↔ 真盲四」**（一 = 旧 rubric，四 = 现行 rubric）：完全一致 **12.5% → 18.8%**、±1 档 **87.5% → 93.8%**、平均带符号差 **−0.88 → −0.47**、掉出 ±1 档的点 **2 → 1**。**但这一对同样只能读出"本轮复测的指标有改善"，读不出"那两处改动确实有效"** —— 每轮只有一个判官实例、而且互不相同（真盲四 ↔ 五 的实测噪声见上一节：10/16 个点会动），所以「rubric 改动起效」与「这一轮判官手松/手紧」**分不开**；能确定的只有另一半：**37.5% 与 50.0% 是被泄漏撑起来的，不是 rubric 的功劳**（判官在量表里读到了答案）。

### 盲判四（真盲 · 现行基线）的逐点

A–F 是六位考生的匿名代号；A / B / E / F 有话语组织，C / D 属 A2、只有语法与互动两项。

```text
 A   语法 -0.5   话语 -0.5   互动  0
 B   语法 +0.5   话语 +0.5   互动  0
 C   语法 -1                   互动 -1.5   ← A2；唯一掉出 ±1 档的点（官方 5 → 3.5）
 D   语法 -0.5                 互动 -1     ← A2
 E   语法 -0.5   话语 -0.5   互动 -0.5
 F   语法 -1     话语 -1     互动  0
```

**残余偏差仍有方向**：A / D / E / F 多为 **−0.5**、B 为 **+0.5**，整体 **−0.47** —— **仍然偏严**（比 −0.88 好，但没有消掉）。**不要把这读成"已无系统性偏差"。**

### 一条工具边界：A2 的互动交际在纯转写里基本测不到

这一条是**盲判四的判官自己给出的解释**，值得单列：**A2 互动交际的判据只有两条** —— 能不能维持简单交流、需要多少提示与支持；而切分后的文本里**看不到考官提示了几次、沉默了多久**。所以上面 **C 的 −1.5 档很可能主要是"证据缺失"，不是判错**。

这是**工具的边界**，不是某一轮的偶然：只有转写、没有音频与提示 / 沉默记录时，A2 的互动交际本来就没有足够证据。做法上**宜标 `待补`、或明确标注为「推断」**（判档提醒已写进 `references/02-rubric.md` 第四节）；要真评就得回到音频，或补上"考官提示了几次 / 沉默多久"这类的记录。

### 证据口径敏感性：那 2 个点现在有证据了，但结论没变

**（2026-09-30 更新：这一节的前提已经变了。）** 旧版这一节讲的是：C / D 属 A2，它们的互动交际点只有纯转写，按本 skill 的纪律本该标 `待补`，所以"不该和有充分证据的点混在同一个一致率里"，并据此给出剔除后的 14 点口径。现在多了 `scripts/kpf_interact.py` —— 它从**音频**里量出"考官提示了几次、沉默了多久"，这两点**有证据了**，第五轮的判官也确实拿到并逐条引用了。所以：**"证据不足"这条剔除理由不再成立。**

三组口径仍然列出来（同一批逐点差值；**对外只报第一行**）：

| 口径 | 可比点 | 完全一致 | ±1 档 | 平均带符号差 |
|---|---|---|---|---|
| 全部（**对外基线**） | 16 | 3/16 = 18.8% | 15/16 = 93.8% | −0.53 |
| 剔除 A2 互动交际 2 点 | 14 | 3/14 = 21.4% | **14/14 = 100.0%** | −0.43 |
| 剔除全部互动交际 6 点 | 10 | **1/10 = 10.0%** | 10/10 = 100.0% | −0.45 |

复算命令（语料在仓库外的私有校准目录；第五轮是 `cases-blind5`）：

```bash
R=<cases-blind5 目录>
python3 scripts/kpf_calibrate.py --root $R                                     # 16 点
python3 scripts/kpf_calibrate.py --root $R --exclude KET:互动交际               # 14 点
python3 scripts/kpf_calibrate.py --root $R --exclude KET:互动交际 \
    --exclude PET:互动交际 --exclude FCE:互动交际                               # 10 点
```

**读数要点（第五轮）：**

- **剔掉那 2 个点确实会让 ±1 档变成 100%** —— 第五轮唯一掉出 ±1 档的点**还是** A2 的互动交际（这回是 D，−1.5）。**但这不是"证据不足"的锅**：本轮那两个点有证据、判官也引用了，它照样压得低。所以这个 100% 只说明"唯一跨档的例外落在哪一维"，**不能拿来证明"剔除后就更准"**。
- **18.8% 的分子是 3 个点**：A 的互动交际、B 的语法与词汇、B 的互动交际。与第四轮相比，命中从"全在互动交际"变成"2 个互动 + 1 个语法" —— 这个变化**同样落在判官噪声的量级里**（上一节：同语料换判官，16 点里 10 点会动）。
- **AI 真正负责的两个维度（语法与词汇 + 话语组织）是完全一致 1/10**（第四轮 0/10）：10 个点里 9 个差半档或一档，方向偏严（8 点 −0.5、1 点 −1.0、1 点 0）。**产品声称能给的那两项，完全一致率仍然只有一成。** 这一条比"18.8%"更该被记住。
- **不要再用"剔除 2 点后 100%"对外报数**：那 2 个点现在有证据，剔掉它们等于把"我们判得最不准的地方"从统计里拿走。

（B1 / B2 的互动交际点：A2 Key 与 B1 Preliminary 两条视频本轮拿到了证据；**B2 那条两位考生音高重合，脚本拒答、只有沉默类指标** —— 这一条**仍然**是没覆盖的口径，别假装已经解决。）

盲判一轮 `|差| ≥ 1 档` 共 **11 条**（其中 9 条正好差 1.0）。**16 个点全部偏低或持平、0 点偏高；偏差以顶端为主、但中段也有**：官方 **5 档**的 11 个点贡献了 **10.5/14 = 75%** 的绝对误差，模式是"该给 5 时不给 5"（三位被考官全给 5 的考生，盲判在语法与词汇 / 话语组织 / 互动交际上给成 4 / 4.5；KET 两位的互动交际被压到 3 与 3.5，差 −2 与 −1.5）；官方 **3–4 档**的 5 个点里**有 4 个也不一致**，贡献 **3.5/14 = 25%**。所以"中段无偏差"这个读法是错的——逐维度 `±1 档` 一致率 100%（语法与词汇 6/6、话语组织 4/4）只说明"没有差过一档"，**不等于没有偏差**（这两项的完全一致率只有 1/6 = 16.7% 与 0/4 = 0%）。**后续校准不能只盯 5 档。**

二轮的**逐点档位差分布**（这是"能不能相加"的关键）：

| 档位差 | 点数 |
|---|---|
| 0.0 | 6 |
| ±0.5 | 8 |
| ±1.0 | 1 |
| −1.5 | 1（唯一超出 ±1 档的点） |

**这张表不能按"列相加"读**：`±1 档` 是**包含关系**——0 与 ±0.5 都算在它里面（6 + 8 + 1 = 15，正是 15/16 = 93.8%），所以它**不能与"完全一致"相加**；校准器的表头写的也是「±1 档（含完全一致）」。

| 互动交际 | 6 | **4/6 = 66.7%** | 6/6 = 100% | **0.00** |

**这一节的所有数字都是污染轮的**（下表与下面的"净变化"同理）：**完全一致 6/16 = 37.5%（二轮）→ 8/16 = 50.0%（三轮）**、**±1 档 15/16 = 93.8%（二轮）→ 16/16 = 100.0%（三轮）**、**整体偏差 −0.34（二轮）→ −0.06（三轮）**；`|差| ≥ 1 档` 从二轮的 **2 条**降到三轮的 **0 条**。**这是两个污染轮之间的比较，只作记录**——尤其**不要把 50.0% / 100.0% 当基线或当"改 rubric 的效果"**。

三轮的**逐点档位差分布**（这是"能不能相加"的关键）：

| 档位差 | 点数 |
|---|---|
| 0.0 | 8 |
| ±0.5 | 8（偏低 5 / 偏高 3） |
| ≥1.0 | 0 |

**剩下的 8 个不一致全部只有半档，而且方向不一**（有高有低）——**整体平均偏差很小（−0.06 档），但这是正负抵消的结果**：按考生看，FCE 的第二位考生三项**全部高估 0.5 档**，而 FCE 第一位、KET 两位、PET 第二位各有 0.5 档的低估。所以只能说"**本批样本的整体平均偏差小**"，**不能**据此宣称没有系统性偏差，也**不能**把剩余的 0.5 档误差当成随机噪声——它可能是个案效应，需要更多判官或更多语料才能分辨。但这**不等于"已经达标"**：`1.0.0` 的门槛仍未达（见下面的边界与结论）。`±1 档` 是**包含关系**（8 + 8 = 16，正是 16/16 = 100.0%），**不能与"完全一致"相加**。

```text

 FCE 考生二   语法词汇 3→3.5(+0.5) 话语组织 3→3.5(+0.5) 互动交际 4→4.5(+0.5)
 KET 考生一   语法词汇 4→3.5(-0.5)                     互动交际 5→4.5(-0.5)
 KET 考生二   语法词汇 4→4(0)                          互动交际 5→5(0)
 PET 考生一   语法词汇 5→5(0)      话语组织 5→5(0)      互动交际 5→5(0)
 PET 考生二   语法词汇 5→5(0)      话语组织 5→4.5(-0.5) 互动交际 5→5(0)
```

### 二轮的一条发现（污染轮 · 数字不作数）：顶端抬上来了，中段还是偏严

**锚点确实把顶端抬上来了**：PET 两位考生的六个点在一轮里全是 4 / 4.5 档，二轮升到 4.5–5 档、**没有再出现 4 档**；其中一位的三项（语法与词汇 / 话语组织 / 互动交际）**全部命中 5 档**，与考官完全一致。

**但二轮唯一掉出 ±1 档的点，恰恰是中档考生的语法与词汇**——官方 3、盲判给 1.5（**−1.5 档**）。判官的理由是**严格按表走的**：B2 语法词汇的 **1 档逐字等于** A2 的 5 档（"对简单语法形式有良好的掌控 + 日常情境一系列恰当词汇"，见 `references/02-rubric.md` 用法第 2 条），而这位考生**只满足后半个条件**（词汇够、形式控制不足），按偶数档口径落 1.5。**结论：「半个条件满足」这类中段判法仍偏严——下一个杠杆在中段，不在顶端。**

### 中段轨迹（来自污染轮 · 只作记录，不作 rubric 效果的证据）

**下面这条轨迹的每一轮（含轨迹本身）都出自污染轮**——那两轮判官读的量表里写着官方分与历轮结果，也就是说**判官甚至可能读到过这条轨迹**。所以它记录的是"泄漏之下这条线长什么样"，**不是"改 rubric 把中段救回来了"的证据**。真盲的第四轮里没有出现这种塌方（逐点见上：唯一掉出 ±1 档的是 C 的互动交际，没有哪个点被压到 1.5 那种幅度）。

按二轮那条结论去改 rubric（`references/02-rubric.md` §一 补上「B2 的 1 档与 3 档共享同一句掌控判据」）之后，**同一位中档考生的「语法与词汇」轨迹**是：

| 轮次 | 盲判给的档 | 差 |
|---|---|---|
| 盲判一轮 | 3 | 0（正好中） |
| 盲判二轮 | 1.5 | **−1.5 档**（二轮唯一掉出 ±1 的点） |
| 盲判三轮 | 3.5 | **+0.5 档** |

即：**第二轮把注意力推往顶端时，中段被压坏了**（官方 3 → 盲判 1.5）；**第三轮那条「1 档与 3 档共享同一句掌控判据」把中段救回来**（3.5），**而顶端没丢**——PET 两位考生的六个点在二轮已到 {4.5, 5}，三轮仍是 {5, 5, 5, 5, 4.5, 5}。

**因果链是可见的**：三轮判官在报告里**直接引用了这条规则**作为它给 3.5 的依据（原报告引文：「按量表 B2 一条"错误密度只用来定位档位，不能脱离档位描述单独扣分"不往下压」——这条正是「1 档与 3 档共享同一句掌控判据」的收口句）：它不再因为"简单形式有可见错误"就往 3 档以下压。**但这条因果链同样长在泄漏之上**：判官读到的那份量表里写着官方分，所以"它照这条规则走"不能当"这条规则把那 0.5 档掰回来了"的证据。

### 非盲对照证明了什么

**同一位判官、同一批语料，只要事先看过官方分，完全一致率就从 12.5%（真盲一轮）跳到 87.5%（非盲）。** 这组数字只能当"锚定效应有多大"的对照、**不得再作为结论**。因此：

- 此前发布的 **8/10 = 80%、±1 档 10/10**（4 case 版本）与 **14/16 = 87.5%、±1 档 16/16**（6 case 版本）**都是非盲数字，都被锚定高估**；
- **对外基线是真盲**：数据是上面的**盲判五**（3/16 = 18.8% / 15/16 = 93.8% / −0.53；盲判四是 −0.47）；盲判一（2/16 = 12.5% / 14/16 = 87.5% / −0.88）保留作真盲对照；二、三轮（6/16 = 37.5% / 15/16 = 93.8% / −0.34、8/16 = 50.0% / 16/16 = 100.0% / −0.06）**因量表泄漏答案而不作数**，只作"泄漏能把数字撑到多高"的记录。**报基线时不要再把"把 A2 那两点剔掉"当成更准的口径** —— 它们在第五轮已经有音频证据，剔除只是把判得最不准的地方从统计里拿掉（三组口径见上面的「证据口径敏感性」）。

### 读这些数字时必须同时看的六个边界

1. **样本严重偏上 → 四轮都只验证了 3–5 档。** 16 个官方分点**全部落在 3–5 档**、**0 个**落在 0/1/2 档。作者实际带的学生多在 1–3 档，**低档（0–2）仍然没有任何外部验证**。四轮说的都是"3–5 档这一带对得上"，不是"分项分可信"。
2. **语法与词汇另有已识别的转写偏差，方向与幅度都未测量** —— 本机 whisper 会自动把学习者的错误改对（实测：官方评语引用的原句含三处错误，转写把它们改成了正确形式），所以转写比真实口语更正确。它对一致率的影响**可能美化、也可能加大偏差，方向与幅度都没有测量**，所以语法维度这一项的数字要按"已知有偏差、大小未知"来读。
3. **发音维度仍是 0 校准。** 官方样题是**对话考试**，而讯飞 ISE 是**朗读型**接口、必须有参考文本——本工具无法在对话录音上评发音。发音点全部是"AI 缺值"。
4. **锚定效应已实测（2026-09-30）。** 同一批语料，判官**知道** vs **不知道**官方分，完全一致率 **87.5%（非盲）vs 12.5%（真盲一轮）/ 18.8%（真盲四、五轮）**——二、三轮的 37.5% / 50.0% 是污染数字，**不作锚定效应的证据**。两组一起看：**知道分的那一组（87.5%）仍高于三轮真盲**。结论是方法上的：**判档必须在看官方分之前完成**，而且**判官读的那份量表必须已经抹掉校准数字**，否则数字不成立——顺序与留证办法见「一、语料怎么攒」里的「判档顺序」。
5. **"绿灯门槛太松"（2026-09-30 新增）。** 校准器的主指标是 `±1 档` 一致率、阈值 80%；真盲**一轮**整体偏低 0.88 档、`|差| ≥ 1 档` 有 11 条，**却仍然算绿灯**（87.5% ≥ 80%）；真盲**四轮**同样是绿灯（15/16 = 93.8% ≥ 80%），而**完全一致率只有 18.8%**——**离"完全一致"差得更远**。所以 **绿灯 ≠ 判分可用**：**完全一致率与系统性偏差才是主指标**，`±1 档` 只是"相邻档分歧在教学上是否可以接受"的旁证。**阈值本身没有改，改的是对它的读法。**
6. **证据口径与判官噪声（2026-09-30，第五轮之后重写）。** 这一条原来讲的是"A2 那两个点证据不足、该剔除"。第五轮把证据补上了（`kpf_interact.py` 从音频量出考官提示次数与沉默统计，判官也确实引用了），**结果是那两个点没有变准**（C +0.5、D −0.5，两点平均仍 −1.25）。于是两件事都要改口：① **"证据不足"不再是剔除那两点的理由** —— 对外报数就用 16 点口径；② 更要紧的是，第四 ↔ 第五轮**同语料、同量表、只换了一个判官**，**16 个点里 10 个动了 0.5 档（其中 6 个与互动交际无关）** → **判官噪声就是这个量级，任何跨轮比较都必须先扣掉它**。边界 5 说的"完全一致率才是主指标"，在 AI 真正负责的两维上是 **1/10**（第四轮是 0/10）。

### 这四轮数字的四条限制（与上面六个边界一起读）

1. **每一轮只有一个判官实例，而且四个真盲轮是四个不同的实例。** 所以 **12.5% → 18.8% 这一路（真盲对真盲）里，"rubric 改动起效"与"这一轮判官手松/手紧"分不开**——n = 1，只能看方向，**不能当精度指标**。要立住得同一批语料跑 2–3 个判官看分布。
2. **语料没变**：还是同 6 条 case 反复用，四轮都不是新样本、也不是新语料（**多轮 = 同语料换 rubric 重判，不是多批独立样本**）。
3. **低档（0–2 档）与发音维度仍然零覆盖**：16 个可比点**全部落在 3–5 档**，发音 6 个点**全是 AI 缺值**（就是上面边界 1 与边界 3 说的两件事，在这里重述，是因为它们决定了这四轮数字能覆盖多远）。
4. **任何写进量表的校准数字都会污染盲判**（2026-09-30 新增）：判官按流程一定要读量表，而量表里只要写着官方分或历轮结果（"三位被考官全给 5""11 个点是 5 档""中段轨迹 3 → 1.5 → 3.5"这类句子），**判官读到量表就读到了答案**——换判官实例、抹姓名、把上一轮的产物挪出隔离目录，都堵不住这条路。**所以校准数字只写在本文件里，`references/02-rubric.md` 里一句不留**（生成与自查办法见下面的「判档顺序」）。

**残余偏差仍然是"偏严"、而且有方向**：真盲第五轮里 A / D / E / F 多为 −0.5，整体 **−0.53**；第四轮 −0.47、第一轮 −0.88。**五轮真盲的方向一次都没变过（全部偏严）**，但**幅度在 −0.47 ~ −0.88 之间摆动，而这个摆动与"换一个判官"同量级**（第四 ↔ 第五同语料、同 rubric，16 个点里 10 个动 0.5 档）—— 所以**既不能宣称"偏差已消掉"，也不能把某两轮之间的细小差别记成规则改动或证据补全的效果**。

**结论**：门槛判据是覆盖区间，不是"跑过一次"。低档（0–2）与发音维度的外部真值仍然为零；**对外基线是盲判五**（真盲、现行 rubric + 互动证据）：完全一致 **3/16 = 18.8%**、±1 档 **15/16 = 93.8%**、偏差 **−0.53**。可比的改进仍然只有**真盲一 ↔ 真盲四**那一对（12.5% → 18.8%、−0.88 → −0.47），而且它同样只能读成"本轮复测指标有改善"；**真盲四 ↔ 五 之间没有可归因的效果** —— 差的不是量表，是判官（同语料 16 点动 10 点）。**这一轮最重要的产出是否证**：A2 互动交际那两点**在补上音频证据之后仍然偏低**（C +0.5、D −0.5，两点平均仍 −1.25），所以**"证据不足"不是它们偏低的解释**，判严另有来源。**而 AI 真正负责的语法与词汇 + 话语组织，完全一致率只有 1/10。** 所以 `1.0.0` 的门槛（≥5 个真实 case 且低档也有真值）**仍未达**；下一步要补的是低档与发音的真值，以及**每轮跑 2–3 个判官把噪声量出来**。带名字的完整报告、音视频与转写都留在仓库外的私有校准目录，不进仓库。

## 学生样本（非盲 · 2026-10-04 起累积）

### 三条方向（**方向性观察，不是结论**）

1. **语法与词汇：AI 偏低 0.67 档**（3 次里低 2 点、持平 1 点，两次低 1.00、一次持平）。两次偏低出在同一个判据上：AI 卡 B2 的 3 档要求「尝试一些复杂结构」，学生确实没从句，AI 就落 2 / 2.5；老师按词汇量与整体印象给 3 / 3.5。**方向与真盲判实测的偏严一致**（−0.53），所以这不像"这次手抖"，更像同一个偏差在真实教学档位上的复现。

   一个口径提醒：这里比的是**教学映射后的档位**（`to_band()`）与老师的档，映射表本身不是官方换算表。

### 读这三个数字必须同时看的五条边界

1. **全部非盲**（老师先看到 AI 档位与引擎分）。**不得进盲判基线，不得与 `cases-blind5` 的 18.8% 混着报。**
2. **3 个 case 是同一个学生**。所以"语法偏低 0.67"目前只是"对这一个人的方向性观察"，不是分布，更不是精度指标。
3. **档位只落在 2–3.5 与 4.5–5 两带**：低档 0–2 仍然一个点都没有，`1.0.0` 那道门槛（≥5 个真实 case 且低档有真值）**没有因此松动**。
4. **发音真值只有一位老师、判过三次**：那 ±0.5 是否稳定、是否是这位老师个人的尺度，**没有任何外部印证**。
5. **发音维度比的是教学映射**，不是官方量表分；官方量表 4 档与 5 档之间本来也没有公布过换算办法。

```bash
python3 scripts/kpf_calibrate.py \
    --root "$HOME/Documents/口语批改工作区/_calibration" --ai-party ai-only
```

报告给出逐维度一致率、系统性偏差方向、混淆矩阵与分歧清单；本节的数字就该被整段重算。**分歧清单才是真正有用的部分**——每条都带着"AI 给了什么 / 老师给了什么 / 老师为什么这么给 / AI 当时引了什么证据"，它就是改规则的素材（用法见下面「三、怎么用报告」）。

**要纠偏，缺的不是更多同类样本，而是这三样**：

1. **低档（0–2）的真值** —— 现有样本全在 2 档以上。"AI 偏严"在低档是否成立、偏多少，**完全没测过**。这是目前最值钱的一批数据。
2. **把"真盲"和"非盲"分开** —— 老师先看 AI 档再给档，锚定效应已实测能到几十个百分点（见上面「非盲对照证明了什么」）。想读精度，就得**先写自己的档、再看 AI**；做不到的话，这批样本永远只能读方向。
3. **多个学生** —— 现在 3 个点来自同一个人。同一维度至少覆盖 3–5 个不同学生，才谈得上"系统性偏差"。

**预登记**（写下这一节时的预期，供以后对照）：如果"AI 语法偏低"真是判档口径的问题，那么在**老师先给档、后看 AI** 的样本上，语法与词汇的平均带符号差**应当仍然是负的**。如果随着样本增加它逐渐趋近 0，就说明现在这 −0.67 里主要是锚定或单个学生的特殊性，而不是口径问题——**那时该改的是样本流程，不是量表**。

## 一、语料怎么攒

放在**仓库外**，一个 case 一个目录（目录名与 `case_id` 都不要写真实姓名——校准报告可能被贴进 issue 或聊天记录）：

```text
~/Documents/口语批改工作区/_calibration/<日期>-<学生代号>/      如 2026-10-08-甲
  audio/                     原音视频（只留本机，永不提交）
  <文件名>--local.json       本机转写（脚本要读它取问答切分）
  ai-底稿.md                 kpf_analyze.py 出的底稿（可读）
  ai-分项.json               AI 四项预估，格式见 templates/ai-marks.json
  teacher.json               老师的真实给分，格式见 templates/teacher-marks.json
```

- 学生只用代号（甲 / 乙 / 丙）。
- `teacher.json` 是**必需**的；`ai-分项.json` 可选——没有它时工具会退而从 `作业记录.md` 的「分项评分 / 四项预估」表格里解析档位，两条路都走不通就报错（不会把这个 case 悄悄跳过）。
- **`teacher.json` 里最值钱的是 `notes`**（每个维度一句人话，老师为什么给这个档）和 `would_correct`（老师真的会改的句子）。只看分差不知道改哪儿，看到理由才知道该收紧哪条锚点。
- 独白 / 自问自答的 `互动交际` 写 `null`：本来就没有对手方，不要为了凑数填一个分。老师给 `null` 的维度不进统计，但会单独列出来。

### 判档顺序（纪律，不是建议）

**判档必须在看官方分 / 老师分之前完成。** 这不是洁癖：实测同一批语料，**事先知道官方分时完全一致率 87.5%，不知道时只有 12.5%（真盲一轮）/ 18.8%（真盲四轮、五轮）**（数字见上面「五轮盲判结果」的边界 4；二、三轮的 37.5% / 50.0% 是"量表里写着答案"撑出来的，不作锚定效应的证据）。照这个顺序做：

1. **先只拿语料判档**——按**净化版量表副本**独立判（副本怎么生成与自查见下一条纪律），写出 `ai-底稿.md` 与 `ai-分项.json`；
2. **判完之后**才去写 `teacher.json`（老师 / 官方的真实给分）；
3. 判档时用**隔离目录**：把语料复制到仓库与工作区之外的一个空目录里跑，**把考生姓名替换成占位符**，全程不看任何官方分；
4. **保留文件 mtime**：`ai-分项.json` 的写入时间早于 `teacher.json`，这就是"这次判档是盲的"的留证。

**量表副本纪律（硬纪律，不是建议——判官只读净化版，不读仓库那份）：** 判官判档时读的必须是**净化版量表副本**，**不读仓库里的 `references/02-rubric.md`**。**这一条不是洁癖，是踩过坑之后定死的**：仓库那份量表的"用法"节里曾经写着这样几样东西——**"三位（被考官全给 5 的）考生"**、**"11 个点是 5 档"**、**"中段轨迹 3 → 1.5 → 3.5"**，以及各轮的一致率与偏差；而盲判流程又要求判官读这份量表，于是**判官读到量表就读到了答案**：它不用听音频就知道该往哪几档靠、也不用推理就知道中段该给 3.5。**换判官实例、抹姓名、把旧报告挪走，都堵不住这条路** —— 泄漏发生在"判官读什么"这一层，不在"判官是谁"。

做法（每轮判档前必做）：用私有校准目录里的**净化脚本**从仓库那份量表生成副本——脚本**只做一件事**：把"本轮 / 历轮盲判…%""官方…档""三位考生全 5""11 个点是 5 档""轨迹：…"这类**校准叙事**抹掉，规则、档位表、阈值表一字不动；副本放进隔离目录给判官，仓库那份原件不进隔离目录。生成后 grep 一遍副本，确认**不含百分比、不含"官方给了几档 / 三位考生全 5 / 11 个点是 5 档 / 轨迹"这类字样**。

**硬在哪两条**：① **判官读的必须是从量表生成的净化版副本**，拿不到副本、或副本没 grep 过，这一轮的判档**不算盲判**（数字只能进"非盲对照"，不许进基线）；② **任何写进量表的东西，先问一句"判官读了会不会看到答案"** —— 会，就只写在本文件里，量表里一句不留。第 2、3 轮就是被这条规矩的前身漏掉的。

**复测（多轮）时再加两条纪律**：**每轮换一个全新判官实例**，并且**把上一轮的产物挪出隔离目录**（判官看不到上一轮给过什么，避免锚定到上一轮的分数）；同时记住**多轮 = 同一批语料换 rubric 重判，不是多批独立样本**——它只能说明"改 rubric 后方向有没有变"，不增加样本量。

以后每条新 case 都照这个顺序做。反过来的话（先看了 `teacher.json` 再补 `ai-分项.json`），这条 case 的数字只能标成"**非盲对照**"，不许进基线统计。

## 二、怎么算指标

```bash
# 指定若干 case 目录
python3 scripts/kpf_calibrate.py <case目录> <case目录> ...

# 或者扫一个工作区的一级子目录（含 teacher.json 的才算 case）
python3 scripts/kpf_calibrate.py --root ~/Documents/口语批改工作区/_calibration

# 换阈值 / 只看 AI 侧明确标了 AI 的行 / 顺手存一份报告
python3 scripts/kpf_calibrate.py --root <工作区> --min-agreement 0.8 --ai-party ai-only --out <报告.md>
```

工具只读输入、离线、不联网、不读凭证、不碰音频与转写本体。报告里有五块：

| 块 | 看什么 |
|---|---|
| 一、逐维度一致率 | **主指标是 ±1 档一致率**（相邻档分歧在教学上可以接受）——它**包含完全一致**，所以两者不能相加；完全一致率是更严的次指标。另给平均带符号差与平均绝对差 |
| 二、系统性偏差 | AI 整体偏高还是偏低、**哪个维度最容易偏**、偏高/持平/偏低各几点 |
| 三、混淆矩阵 | 每个维度一张"AI 给了几档 × 老师给了几档"的矩阵，一眼看出往哪个方向堆 |
| 四、分歧清单 | AI 给什么 / 老师给什么 / 老师理由 / **AI 当时引的证据**——这是改规则时唯一的入口 |
| 五、不进统计的部分 | 老师给 `null`（无证据）与 AI 缺值的点，明说是"无证据"而不是零分 |

`--min-agreement` 默认 0.8：**±1 档一致率低于它就退出码 1**。进入统计的 case 少于 3 个时，工具只当"冒烟"、明确说数字不能用来判红。

## 三、怎么用报告（关键：先归纳一个偏差，不要逐案打补丁）

1. **读分歧清单**，先只看 `|差| ≥ 1 档` 的条目，跳过老师置信 `low`、也跳过双方都没写理由的条目。
2. **归纳出一个系统性偏差**——一句话说得出来才算数，例如"AI 在语法与词汇上普遍比老师高 1 档，因为它把'错误可见但不影响理解'都算到了 3 档"，或"AI 把口语里的重复和犹豫算进了话语组织，老师不算"。
3. **改判定口径**：动 `references/02-rubric.md` 的锚点或 `references/03-scoring-rules.md` 的证据等级。**改的是口径，不是某个学生的分。**
4. **同步 `references/06-verification.md` §8.4 锚点表**（改了阈值/数值就必须同步，否则 `check_consistency.py` 会报漂移）。
5. **为这个偏差补一个匿名夹具**（见下一节），让它成为回归用例——以后谁再改回去，`make check` 会红。
6. **`make check` 全绿**后再跑一次校准，确认一致率真的上升。
7. **在 `CHANGELOG.md` 记一行**，带上数字：`因 N 个真实样本，±1 档一致率 X% → Y%`。

一次只改一个偏差。同时改三处口径，下次报告变好也不知道是哪一处起的作用。

## 四、怎么把真实 case 变成可公开的夹具

```bash
python3 scripts/kpf_anonymize.py <真实case目录> --out <产物目录> --dry-run   # 先看会替换什么
python3 scripts/kpf_anonymize.py <真实case目录> --out <产物目录>
```

替换规则（都在帮助里有原文）：

| 原样 | 换成 |
|---|---|
| 真实姓名 | 学生甲 / 学生乙 / 学生丙（可用 `--map 姓名=代号` 指定） |
| 班号（`<级别字母><2–4 位数字>`） | `FCE-A` 这类形式 |
| 家目录绝对路径 | `<工作目录>`（保留后面的目录结构） |
| 音视频文件名 | `P<页号>-<代号>` + 原扩展名 |
| 转写 JSON 的 `meta.student` / `class` / `file` | 一并替换 |

**保留**：所有英文原句、分数、耗时、指标——夹具的价值就在错误类型与数据形态，改了就没用了。

写完它会**自动复扫一遍**产物目录（姓名 / 班号 / 绝对路径 / 产物 JSON 可解析），有残留就退出码 1 并指出位置。产物目录里不要放真音频：`--media` 默认 `skip`（只改引用名），要授权时才用 `copy`。

`--mapping-out <路径>` 可以把"原名 → 代号"对照表写到你自己的留档位置（**禁止写在 `--out` 里**，那等于把对照表一起公开了）。

一次实际运行（合成样例）长这样：

```text
$ python3 scripts/kpf_anonymize.py <真实case> --out <产物目录> --names 某姓名
已写出产物：<产物目录>/<case>/
文本 2 个（内容已替换）· 音视频 0 个（策略 skip）· 其他二进制 0 个（策略 skip）

自检通过：<产物目录> 下没有姓名 / 班号 / 绝对路径残留，产物 JSON 均可解析
```

注意两个**它做不到的事**，产物要自己复核：

- 姓名是自动识别 + 启发式兜底的。识别不到时会明确提示（`没识别到学生姓名…请用 --names 显式给出`），此时用 `--names` 显式给，别当它已经改好了。
- 它做的是文本替换，不重排句子：如果原句里本来就带着"学生"两个字（例如标题写成"学生某某 口语批改底稿"），替换后会留下 `学生学生甲` 这种叠字。这类残留不影响校验，但公开前值得手工顺一遍。

## 五、公开与私有的边界

| | 留在本机的 | 可以进公开仓库的 |
|---|---|---|
| 音频 / 视频 | ✅ 全部 | ❌ 一律不进（音视频后缀与 `*.local.json` 都在 `.gitignore` 里） |
| 真实姓名 / 班级 / 学校 | ✅ | ❌ |
| 转写全文 | ✅ | ⚠️ 只在匿名夹具里，且只保留必要的原句 |
| 分数与指标 | ✅ | ✅ 可以 |
| 规则与方法论 | — | ✅ 全部（`references/`、`docs/`、`SKILL.md`） |
| 一致率结论 | ✅ | ✅ 可以（这正是校准要产出的对外结论） |

一句话：**公开仓库只拿到"规则 + 匿名夹具 + 指标结论"这三样**，真实语料与音频永远不出本机。

## 六、第一批该怎么做（起步建议）

1. **先攒 3–5 个 case**，不求多：覆盖不同级别（尽量有 KET/PET/FCE 各一）、不同水平（一个明显好的、一个明显弱的、一两个中间），并且**要挑你已经给过分、还能说清为什么的**。凑不满 3 个以前，工具只会给"冒烟"结论。
2. `teacher.json` 一次填完，`notes` 一定要写——只填分不写理由，下次只能看到"偏了 1 档"，看不到"该改哪条锚点"。
3. 跑第一份报告：

   ```bash
   python3 scripts/kpf_calibrate.py --root ~/Documents/口语批改工作区/_calibration --out <报告.md>
   ```
